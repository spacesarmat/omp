<h1 align="center">OMP — Open Movie Player</h1>

<p align="center">Медиаплеер для телевизоров LG (webOS 4.0+), Android TV и Android-телефонов, который смотрит фильмы и сериалы прямо из <a href="https://github.com/YouROK/TorrServer">TorrServer</a> в домашней сети.</p>

<p align="center"><a href="https://github.com/spacesarmat/omp/releases/latest">Скачать последнюю версию</a></p>

## Что умеет

| Где | Что |
|---|---|
| **Телевизор LG (webOS)** | Каталог TorrServer с категориями и 4 видами, сериалы по сезонам, главы и пропуск заставки, «История» с отметкой, где смотрели, плеер на аппаратном декодере ТВ, дорожки и субтитры, пульт и Magic Remote, обновления в один клик или через Homebrew Channel |
| **Android TV** | Тот же интерфейс, что на LG, и нативный плеер (MKV, HEVC, дорожки, субтитры, главы и пропуск заставки) |
| **Телефон Android** | Каталог, единый поиск по источникам и добавление раздач с категорией, «Смотреть на ТВ» с выбором «Продолжить / Сначала», «Сейчас играет» с главами и мини-плеер, пульт с тачпадом, просмотр во внешнем плеере |
| **TorrServer на телефоне** | Встроенный сервер: если своего нет, OMP запустит его на телефоне, ТВ найдёт его сам |

Главное:

- **Телефон — пульт и второй экран.** Запуск серии на ТВ с телефона, пауза, перемотка, серии, дорожки и громкость прямо с телефона; включение ТВ по сети (LG).
- **Общая история просмотров.** Хранится на TorrServer и видна на всех устройствах; у каждой записи указано, где смотрели: «Телевизор» или «Телефон «имя»».
- **Продолжить с места остановки** на любом устройстве; автопереход к следующей серии.
- **Без своего сервера.** TorrServer запускается прямо на телефоне (arm64) и обновляется вместе с OMP.
- **Поиск серверов и телевизоров в сети**, подключение телефона к ТВ по QR (LG) или коду (Android TV).
- **Главы и пропуск заставки.** Если в файле есть главы, плеер на LG и Android TV показывает их списком, CH+/CH− переходят между главами, есть кнопка «Пропустить заставку»; без глав заставку можно отметить вручную. Переключатели «Пропуск» — в карточке раздачи, общие для ТВ и телефона.
- **Единый поиск по источникам.** Один запрос на телефоне ищет сразу по rutor, nnmclub, rutracker (с входом), Anidub, BigFANGroup, torrent.by и по поиску TorrServer (rutor, Jackett / Prowlarr); одинаковые раздачи объединяются.
- **Обновления сами приходят:** ТВ и телефон проверяют новую версию при запуске, а после обновления приложение один раз показывает «Что нового».

## OMP для Android

Приложение для телефона: каталог TorrServer, запуск фильма на телевизоре LG, пульт, поиск и добавление раздач.

|---|---|

| ![Источники поиска](docs/screenshots/android-sources.png)<br>Источники поиска | |

- **Установка.** Скачайте `OMP-<версия>.apk` со [страницы релиза](https://github.com/spacesarmat/omp/releases/latest) и откройте файл. Android попросит разрешить установку из браузера (или файлового менеджера) — разрешите.
- **Сервер.** Введите адрес TorrServer либо отсканируйте QR-код с телевизора: в OMP на ТВ откройте Настройки → «Подключить телефон».
- **Телевизор.** Выберите ТВ в списке и нажмите «Разрешить» на телевизоре — телефон запомнит его.
- **Просмотр.** «Смотреть на ТВ» запускает OMP на телевизоре с нужным файлом и позицией, телефон становится пультом. Можно открыть поток во внешнем плеере (VLC, MX Player) или скопировать ссылку.
- **Управление плеером.** Пока фильм идёт на телевизоре, экран «Сейчас играет» (и мини-плеер внизу) управляет им с телефона: пауза, перемотка, предыдущая и следующая серия, звук и субтитры, громкость. Телефон и ТВ должны быть в одной сети; работает, когда на ТВ установлен OMP 0.8 или новее (если версия старая, приложение подскажет обновить). Позиция обновляется примерно раз в 0,5 секунды.
- **Продолжить или сначала.** Если у файла есть сохранённая позиция, при запуске на ТВ приложение спрашивает: «Продолжить» с места остановки или «Сначала».
- **Виды каталога.** Каталог можно переключать, как на ТВ: крупные постеры, мелкие постеры, список или компактный вид.
- **Включить телевизор.** Кнопка питания на пульте включает ТВ по сети. Для этого на телевизоре включите «Общие → Устройства → «Включение мобильного ТВ»» (на части моделей — «Включение через Wi‑Fi»).
- **Категории.** При добавлении раздачи можно выбрать категорию «Фильмы», «Сериалы», «Музыка» или «Прочее» — OMP подсказывает её по названию.
- **Единый поиск.** На экране «Добавить» один запрос ищет по всем включённым источникам: поиск TorrServer (rutor, Torznab — Jackett или Prowlarr) и встроенные сайты — rutor, nnmclub, rutracker, Anidub, BigFANGroup, torrent.by. Одинаковые раздачи объединяются в одну строку; результаты можно отфильтровать по качеству и отсортировать по сидам. Источники включаются в «Настройки → Источники поиска»; для rutracker нужен вход (пароль хранится только в защищённом хранилище Android). Остальные трекеры (Kinozal, seedoff, rustorka, labtor и др.) подключаются через Jackett или Prowlarr в TorrServer — см. «Вопросы и ответы». Если rutracker закрыт защитой от ботов (Cloudflare), OMP подскажет, что делать.
- **Главы и пропуск.** В «Сейчас играет» — список глав и переход к соседней; в карточке раздачи блок «Пропуск»: «Пропускать заставку автоматически», «Пропускать титры» и ручные метки заставки для файлов без глав.
- **Что нового.** После обновления приложение один раз показывает список изменений; его можно открыть и в «Настройках» (строка с версией).
- **Обложки.** Для новой раздачи OMP сам находит обложку в TMDB — по ключу из TorrServer (вводится в «Настройках сервера», нужен TorrServer MatriX.138+).
- **История.** Вкладка «История» с фильтром «Все / С телевизора / С телефона»; каталог обновляется жестом «потянуть вниз».
- **Пульт.** Помещается на один экран. Тачпад управляет курсором на LG; в его настройках — скорость, ускорение, «Касание = щелчок» и «Обратная прокрутка»; двумя пальцами прокручиваются страницы на ТВ.
- **Удобство.** Мини-плеер — в «Каталоге» и «Пульте»; «Назад» на главном экране сворачивает приложение (встроенный сервер продолжает работать); значок ТВ в шапке зелёный, когда телевизор подключён.
- **Вопросы и ответы.** В «Настройки → Вопросы и ответы» — ответы на частые вопросы (установка на ТВ, Homebrew Channel, обновление).
- **Обновления.** Приложение проверяет новую версию при запуске и предлагает скачать и установить `.apk` (лента `update-android.json`). Настройки сохраняются.

### TorrServer на телефоне

Если своего сервера нет, OMP запустит TorrServer прямо на телефоне: с экрана подключения (когда сервер не найден) или из Настроек.

- Только для телефонов на arm64.
- Телефон и ТВ должны быть в одной сети Wi‑Fi; на ТВ сервер находится через «Найти в сети».
- Пока сервер работает, в шторке висит уведомление «TorrServer работает» с кнопкой «Остановить».
- Внимание: сервер открыт без пароля и виден всем устройствам в этой сети Wi‑Fi.
- Новые версии TorrServer приходят автоматическими выпусками OMP.
- Если другое устройство не видит сервер: проверьте, что оба в одной сети Wi‑Fi, VPN выключен или разрешает локальную сеть, а в роутере выключена изоляция клиентов (гостевая сеть). На экране подключения есть кнопка «Найти в сети».
- Настройки любого сервера (кэш, предзагрузка, соединения, скорость) меняются в «Настройки → Настройки сервера».

## OMP для Android TV

Тот же APK, что и для телефона, работает на телевизорах и приставках с Android TV: интерфейс как на LG, нативный плеер (MKV, HEVC, дорожки и субтитры, перемотка как на LG, главы и пропуск заставки, следующая серия).

| | | |
|---|---|---|
| ![Плеер на Android TV](docs/screenshots/androidtv-player.png)<br>Плеер на Android TV | ![Выбор телевизора](docs/screenshots/android-tvlist.png)<br>Выбор телевизора на телефоне | |
| ![Главы на ТВ](docs/screenshots/androidtv-chapters.png)<br>Главы в плеере | ![Пропуск на ТВ](docs/screenshots/androidtv-skip.png)<br>«Пропуск» в карточке | |

- **Установка.** Скачайте `OMP-<версия>.apk` со [страницы релиза](https://github.com/spacesarmat/omp/releases/latest) и установите на ТВ: через файловый менеджер, приложение вроде «Downloader» или по `adb install`. Разрешите установку из неизвестных источников.
- **Код подключения.** На ТВ: Настройки → «Подключить телефон» — появится 4-значный код. На телефоне: «Телевизор» → выберите «Android TV» → введите код.
- **Управление.** После подключения «Смотреть на ТВ», «Сейчас играет» и пульт работают так же, как с LG.
- **Главы и пропуск.** Кнопка «Пропустить заставку», список глав в плеере, CH+/CH− между главами, пропуск титров с переходом к следующей серии — как на LG; переключатели — в карточке раздачи.
- **Поиск.** На экране «Добавить» ТВ ищет по встроенным сайтам, включённым по умолчанию, и по поиску TorrServer. Экрана «Источники поиска» и входа на трекеры на ТВ нет: rutracker настраивается на телефоне.

Ограничения:

- Телефон управляет только OMP на ТВ, не всей системой.
- На Android 10+ система может не выводить OMP на передний план из фона: если ТВ ничего не показал, откройте OMP на ТВ вручную.
- AC3 и DTS воспроизводятся, если их поддерживает ТВ или ресивер.
- Встроенный TorrServer на ТВ не запускается — нужен сервер в сети (например, на телефоне или компьютере).

## Возможности на телевизоре

- Экран входа с историей серверов, правкой логина и пароля и автопоиском серверов в сети (порты 8090 и 5665); смена сервера в «Настройки → Сменить сервер»
- Библиотека с категориями и 4 видами каталога, автообновление — торренты, добавленные с телефона через веб-интерфейс TorrServer, появляются сами
- Сериалы по сезонам, отметки просмотренного, продолжение с места остановки (на ТВ и на сервере), автопереход к следующей серии, пропуск заставки и титров (по главам файла или по ручным меткам), список глав
- Плеер на аппаратном декодере ТВ: MKV/MP4/TS/AVI, H.264/HEVC/AV1, HDR10/HLG/Dolby Vision, AAC/AC3/EAC3/DTS (в пределах возможностей модели)
- Аудиодорожки и субтитры (встроенные и SRT/VTT/ASS в UTF-8 и Windows-1251), запоминание выбора для каждого торрента, размер и сдвиг субтитров
- Плейлисты M3U/M3U8, вложенные плейлисты TorrServer, HLS-потоки
- Добавление торрентов: magnet / хеш / ссылка на .torrent, поиск через Rutor и Torznab (Jackett)
- Вкладка «История»: продолжить просмотр с места остановки; история хранится на TorrServer, у каждой записи указан источник — ТВ или телефон
- Поиск и сортировка по каталогу; страницы прокручиваются колесом Magic Remote и с тачпада телефона
- Значки качества (1080p, 4K, HEVC…) из названия раздачи
- Избранные плейлисты
- Настройки приложения и сервера TorrServer
- Проверка обновлений и установка через Homebrew Channel
- Управление с телефона: запуск на ТВ, «Сейчас играет», пульт
- Параметры запуска (server, magnet, torrent, play)

## Управление

| Пульт | Действие |
|---|---|
| Стрелки, OK | Навигация, выбор |
| Назад | Предыдущий экран (в плеере — сначала скрыть панель) |
| В плеере: OK, Play/Pause | Пауза / продолжить |
| В плеере: влево / вправо | Перемотка (удержание — быстрее) |
| В плеере: вверх или жёлтая | Дорожки и субтитры |
| В плеере: зелёная или Info | Статистика потока |
| В плеере: CH+ / CH− | Следующая / предыдущая глава (если глав нет — следующий / предыдущий файл) |
| Красная | Удалить торрент |
| Синяя | Настройки |

Magic Remote и тачпад LG ThinQ: наведение выбирает элемент, клик нажимает. В плеере клик по изображению — пауза; двойной клик у левого или правого края — перемотка назад или вперёд (5 → 10 → 30 с при повторах; шаг меняется в настройках). Текст (адрес сервера, magnet, поиск) удобно вводить с клавиатуры телефона в LG ThinQ.

## Установка на телевизор LG

Нужен компьютер в той же сети и телевизор в режиме разработчика.

1. На ТВ установите приложение **Developer Mode** из LG Content Store, войдите под аккаунтом разработчика LG (бесплатная регистрация на webostv.developer.lge.com), включите **Dev Mode Status** и **Key Server**, перезагрузите ТВ.
2. Скачайте и установите [Node.js](https://nodejs.org) (LTS).
3. Скачайте проект: `git clone https://github.com/spacesarmat/omp.git` (или архив со страницы релиза) и в его папке выполните `npm install`.
4. Добавьте телевизор (один раз): `npx ares-setup-device` → **add** → имя `tv`, IP телевизора (Настройки → Сеть → Дополнительно), порт `9922`, пользователь `prisoner`.
5. Получите ключ (один раз): `npx ares-novacom --device tv --getkey`, затем укажите passphrase с экрана Developer Mode: `npx ares-setup-device --modify tv --info "passphrase=XXXXXX"`.
6. Установите и запустите: скачайте `OMP-<версия>-webOS.ipk` со страницы [релизов](https://github.com/spacesarmat/omp/releases) и выполните `npx ares-install --device tv OMP-<версия>-webOS.ipk`, либо соберите сами: `npm run package`, `npm run tv:install`, `npm run tv:launch`. Имя устройства по умолчанию — `tv`; другое можно задать переменной `WEBOS_DEVICE`.

> **Windows PowerShell:** если `npx`/`npm` пишут «выполнение сценариев отключено», используйте `npx.cmd` и `npm.cmd` или обычную командную строку (cmd).
>
> **Режим разработчика** нужно продлевать в приложении Developer Mode (срок сессии ограничен, остаток виден в приложении Developer Mode), иначе приложение пропадёт с ТВ. На рутированных ТВ можно ставить `.ipk` через Homebrew Channel.

## Установка через Homebrew Channel

Для рутированных ТВ с [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel).

- Официальный каталог: после включения OMP в каталог приложение можно будет найти и установить прямо в Homebrew Channel.
- Репозиторий OMP: в Homebrew Channel откройте Settings → Add repository и укажите `https://raw.githubusercontent.com/spacesarmat/omp/gh-pages/apps.json`. Либо одной кнопкой из OMP: Настройки → «Добавить репозиторий OMP в Homebrew Channel».

## Обновление

OMP проверяет наличие новой версии при запуске и показывает окно «Доступна версия». Обновить можно тремя способами:

1. **В один клик** — на рутированном ТВ OMP скачивает и ставит новую версию сам.
2. **Через Homebrew Channel** — OMP открывает Homebrew Channel (стартовый экран) или его экран добавления репозитория; обновление ставится оттуда.
3. **С компьютера** — экран «Обновление» показывает QR-код со ссылкой на релиз; скачайте `OMP-<версия>-webOS.ipk` и установите командой `npx ares-install --device tv OMP-<версия>-webOS.ipk`.

Настройки и история просмотра при обновлении сохраняются.

## Параметры запуска

OMP принимает параметры при запуске приложения:

| Ключ | Значение |
|---|---|
| `server` | Адрес TorrServer (`http://192.168.1.10:8090`) — подключиться к этому серверу |
| `magnet` | magnet-ссылка — добавить торрент на сервер |
| `torrent` | Info-hash торрента (40 символов hex) — открыть уже существующий торрент на активном сервере |
| `file` | Номер файла в раздаче (вместе с `torrent`) — сразу начать его воспроизведение |
| `t` | Позиция старта в секундах (вместе с `file`) |
| `play` | Прямая ссылка на видео — сразу начать воспроизведение |
| `title` | Название для `play` (необязательно) |

```bash
ares-launch -d tv com.spacesarmat.torrplayer -p '{"play":"http://192.168.1.10:8090/stream/movie.mkv?link=HASH&index=1&play","title":"Фильм"}'
```

```bash
ares-launch -d tv com.spacesarmat.torrplayer -p '{"torrent":"HASH","file":3,"t":1394}'
```

```bash
luna-send -n 1 luna://com.webos.applicationManager/launch '{"id":"com.spacesarmat.torrplayer","params":{"magnet":"magnet:?xt=urn:btih:HASH"}}'
```

```bash
npm run build      # бандл для Chromium 53+ в dist/
npm run check:boot # проверка запуска из file://
npm run icons      # иконки ТВ из assets/icon.svg
```

CI (GitHub Actions) на каждый push и PR запускает тесты, сборку, упаковку и проверку запуска. Релиз: поднять `version` в `package.json`, слить в `main`, затем `git tag vX.Y.Z && git push origin vX.Y.Z`.

## Ограничения

- Набор кодеков зависит от модели телевизора.
- Если на TorrServer включена авторизация, на новых webOS видео может не воспроизводиться (браузер блокирует логин/пароль в адресе видео).
- Графические субтитры (PGS/VobSub) — только встроенные в видео.
