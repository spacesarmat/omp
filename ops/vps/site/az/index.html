SUALLAR

OMP haqqında tez-tez verilən suallar

OMP nədir?

+-

OMP (Open Movie Player) LG webOS və Android TV qurğuları, eləcə də Android telefonlar üçün pulsuz, açıq mənbəli media pleyerdir. O, ev şəbəkəniz üzərindən TorrServer-dən filmləri və televiziya seriallarını yayımlayır, telefonunuz isə pult və ikinci ekran rolunu oynayır. Abunə ilə reklamdan azad.

TV-də torrenti necə izləyə bilərəm?

+-

TorrServer torrent faylını hissələrlə yükləyir və videonu şəbəkə üzərindən dərhal yayımlayır, beləliklə film tam yüklənməmişdən əvvəl oynamağa başlayır. OMP-ni televizorunuza quraşdırın, TorrServer-ə qoşulun və telefonunuzdan bir film və ya epizod seçin.

Ayrı TorrServer lazımdır?

+-

Zəruri deyil. arm64 dəstəkləyən Android telefonunuzda OMP TorrServer-i GitHub-dan avtomatik yükləyib işə salacaq. Telefonunuz, televizorunuz və server eyni Wi-Fi şəbəkəsində olmalıdır.

Hansı televizorlar və set-top qutuları dəstəklənir?

+-

webOS 4.0 və daha sonrakı versiyalarla işləyən LG televizorları (təxminən 2018-ci ildən etibarən; kök girişi tələb olunmur), Android 8 və daha sonrakı versiyalarla işləyən Android TV və Google TV. Kompüterlər: Windows 10/11, macOS (Intel və Apple Silicon) və Linux. Xiaomi, Sber və Yandex set-top qutuları eyni APK ilə quraşdırılır. Samsung (Tizen) hələ dəstəklənmir.

OMP-ni necə quraşdırım?

+-

Ən asan yol telefonunuzdandır: 'Təqdimatlar' → 'TV-yə OMP quraşdırın' – telefonunuz şəbəkədəki LG və ya Android TV-ni aşkarlayacaq və OMP-ni avtomatik quraşdıracaq. Əl ilə quraşdırma üçün faylları GitHub-dakı ən son buraxılışda tapa bilərsiniz: Android üçün üç APK var – arm64 (demək olar ki, bütün telefonlar), armv7 (bir çox set-top qutusu) və əmin deyilsinizsə universal versiya. Windows üçün quraşdırıcını və ya portativ versiyanı yükləyin. macOS üçün Apple Silicon və ya Intel DMG faylını yükləyin; Linux üçün AppImage və ya deb paketini yükləyin. Apple imzası olmayan macOS üçün: tətbiqin üzərinə sağ klik edib 'Aç' seçin, ya da Terminal-da: xattr -d com.apple.quarantine "/Applications/OMP.app"Kompüterdə APK-lar ADB vasitəsilə quraşdırılır – aşağıdakı addımlara baxın; LG cihazları üçün GitHub-dakı təlimatlara əməl edin.

ADB vasitəsilə Android-ə OMP-i necə quraşdırım?

+-

ADB OMP-ni kompüterdən Android telefonuna, Android TV-yə, Google TV-yə və set-top qutularına quraşdırır. Sizə Windows, macOS və ya Linux işləyən kompüter və USB kabeli (telefon üçün) və ya set-top qutusu ilə ortaq Wi-Fi şəbəkəsi (TV üçün) lazım olacaq.

  1. İnkişafçı rejimini aktivləşdirin: 'Build number' üzərinə yeddi dəfə toxunun (telefon: 'Tənzimləmələr' → 'Telefon haqqında') və ya 'Quruluş' (TV: 'Tənzimləmələr' → 'Sistem' və ya 'Cihaz parametrləri' → 'Cihaz haqqında').
  2. 'Inkişafçılar üçün' bölməsində 'USB səhvlərinin düzəldilməsi'ni aktiv edin və telefonunuzu kabellə qoşun. TV-də 'Şəbəkə səhvlərinin düzəldilməsi'ni aktiv edin və şəbəkə parametrlərində set-top qutunun IP ünvanını tapın.
  3. Əməliyyat sisteminiz üçün Google-un platform-tools paketini yükləyin, arxivi açın və platform-tools qovluğunda terminalı açın. macOS və Linux-da yazın ./adb yerinə adb.
  4. TV üçün əvvəlcə: adb connect <IP>:5555. Bağlantını yoxlayın: adb devices - cihazın yanında yazılmalıdır device. Cihazın ekranında 'Həmişə bu kompüterdən icazə ver' seçimini işarələyin və 'İcazə ver' düyməsini basın.
  5. Memarlığını müəyyən edin: adb shell getprop ro.product.cpu.abi. Cavab arm64-v8a - fayl OMP-<versiya>-arm64.apk, armeabi-v7a - OMP-<versiya>-armv7.apk (bu, çox vaxt 64-bit prosessorlu set-top qutularda belə olur). Əgər əmin deyilsinizsə, ümumi OMP-<versiya>.apk.
  6. GitHub-dakı ən son buraxılışdan APK-ni yükləyin, onu platform-tools qovluğuna yerləşdirin və quraşdırın: adb install -r OMP-<versiya>-arm64.apk. Açar -r Yeni versiyanı köhnəsinin üzərinə quraşdırır və məlumatlarınızı saxlayır. Cavab Success – tamamdır.

Android 11 və daha yeni versiyalarda 'Network Debugging' olmadan: 'Wireless Debugging' → 'Cihazı kodla birləşdirin', sonra adb pair <IP>:<port> bu pəncərədən götürülən kodu istifadə edərək və adb connect <IP>:<port> 'Simsiz Debugging' ekranında göstərilən port.

Ümumi səhvlər

  • unauthorized - Səhvə düzəliş təsdiqlənməyib: cihazın ekranını açın və 'İcazə ver' düyməsini vurun.
  • offline - əlaqə itirilib: adb kill-server, sonra adb connect və ya kabeli yenidən qoşun.
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE - Fərqli imzaya malik OMP artıq quraşdırılıb. OMP-də ehtiyat nüsxə saxlayın ('Tənzimləmələr' → 'Gelişmiş' → 'Ehtiyat nüsxəsi'), köhnə OMP-ni silin (cihazdakı məlumatları, o cümlədən telefonunuzdakı TorrServer və onun tarixçəsi silinəcək) və yenidən quraşdırın.
  • INSTALL_FAILED_INSUFFICIENT_STORAGE - Yeterli yaddaş sahəsi yoxdur: bir qədər yer boşaldın.
  • INSTALL_FAILED_NO_MATCHING_ABIS - APK bu sistemlə uyğun gəlmir: armv7 versiyasından və ya universal versiyasından istifadə edin.

Quraşdırıldıqdan sonra artıq ehtiyacınız yoxdursa, səhvləri düzəltməni (debugging) söndürün.
