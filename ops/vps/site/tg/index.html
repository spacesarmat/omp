СУОЛҲО

Саволҳои зиёд такроршаванда дар бораи OMP

OMP чист?

+-

OMP (Open Movie Player) — плеёри ройгон ва кушодаи мультимедиа барои телевизорҳои LG webOS ва Android TV, инчунин телефонҳои Android мебошад. Он филмҳо ва сериалҳои телевизиониро аз TorrServer тавассути шабакаи хонагии шумо пахш мекунад, дар ҳоле ки телефони шумо ҳамчун пульт ва экрани дуюм хизмат мекунад. Бо обуна бе таблиғот.

Чӣ тавр метавонам торрентҳоро дар телевизиони худ тамошо кунам?

+-

TorrServer торрентро қисм ба қисм зеркашӣ мекунад ва фавран видеоро тавассути шабака пахш мекунад, то филм пеш аз пурра зеркашӣ шуданаш оғоз ёбад. OMP-ро дар телевизиони худ насб кунед, ба TorrServer пайваст шавед ва дар телефони худ филм ё серияро интихоб кунед.

Оё ман ба TorrServer-и алоҳида ниёз дорам?

+-

Ҳатман не. Дар телефони Android бо arm64, OMP ба таври худкор TorrServer-ро аз GitHub зеркашӣ карда, оғоз мекунад. Телефон, телевизор ва сервери шумо бояд дар як шабакаи Wi-Fi бошанд.

Кадом телевизорҳо ва қуттиҳои телевизионӣ дастгирӣ мешаванд?

+-

Телевизорҳои LG бо webOS 4.0 ва навтар (тақрибан аз соли 2018; дастрасии root лозим нест), Android TV ва Google TV бо Android 8 ва навтар. Компютерҳо: Windows 10/11, macOS (Intel ва Apple Silicon) ва Linux. Плитаҳои телевизионии Xiaomi, Sber ва Yandex бо истифода аз як APK насб карда мешаванд. Samsung (Tizen) ҳанӯз дастгирӣ намешавад.

Чӣ тавр OMP-ро насб кунам?

+-

Осонтарин роҳ ин аст, ки аз телефони шумо: 'Танзимот' → 'ОМП-ро дар телевизор насб кунед' – телефони шумо LG ё Android TV-ро дар шабака меёбад ва OMP-ро ба таври худкор насб мекунад. Файлҳо барои насби дастӣ дар навтарин нашри GitHub пайдо мешаванд: барои Android се APK вуҷуд дорад – arm64 (тақрибан ҳамаи телефонҳо), armv7 (бисёр приставкаҳо) ва як нусхаи умумӣ, агар шумо мутмаин набошед. Барои Windows, насбкунанда (installer) ё версияи портативиро зеркашӣ кунед. Барои macOS, DMG-и Apple Silicon ё Intel-ро зеркашӣ кунед; барои Linux, AppImage ё пакети deb-ро зеркашӣ кунед. Барои macOS бидуни имзои Apple: барномаро бо тугмаи рост пахш карда, 'Open'-ро интихоб кунед, ё дар Terminal: xattr -d com.apple.quarantine "/Applications/OMP.app". Дар компютер APK-ҳо тавассути ADB насб мешаванд – қадамҳои зерро бубинед; барои дастгоҳҳои LG дастурҳоро дар GitHub риоя кунед.

Чӣ тавр OMP-ро дар Android тавассути ADB насб кунам?

+-

ADB барномаи OMP-ро аз компютер ба телефони Android, Android TV, Google TV ва қуттиҳои телевизионӣ насб мекунад. Шумо бояд компютер бо Windows, macOS ё Linux ва кабели USB (барои телефон) ё шабакаи Wi-Fi-и муштарак бо қуттии телевизионӣ (барои телевизор) дошта бошед.

  1. Режими таҳиягарро фаъол кунед: ҳафт маротиба ба 'Рақами бино' ламс кунед (телефон: «Танзимот» → «Дар бораи телефон») ё «Build» (телевизор: «Танзимот» → «Система» ё «Танзимоти дастгоҳ» → «Дар бораи дастгоҳ»).
  2. Дар 'Барои таҳиягарон' режими 'Трускании USB'-ро фаъол кунед ва телефони худро бо кабел пайваст кунед. Дар телевизор 'Трускании шабака' (Network debugging)-ро фаъол кунед ва суроғаи IP-и приставкаи телевизиониро дар танзимоти шабака пайдо кунед.
  3. Платформа-тоолс-и Google-ро барои системаи оператсионии худ зеркашӣ кунед, архивро кушоед ва дар ҷузвдони platform-tools терминалро боз кунед. Дар macOS ва Linux чунин нависед ./adb ба ҷои adb.
  4. Барои телевизор, аввал: adb connect <IP>:5555. Пайвастшавиро санҷед: adb devices - дар назди дастгоҳ бояд навишта шавад deviceДар экрани дастгоҳ 'Ҳамеша аз ин компютер иҷозат диҳед'-ро қайд кунед ва тугмаи 'Иҷозат диҳед'-ро пахш кунед.
  5. Архитектураро муайян кунед: adb shell getprop ro.product.cpu.abi. Ҷавоб arm64-v8a - файл OMP-<версия>-arm64.apk, armeabi-v7a - OMP-<версия>-armv7.apk (ин одатан дар бисёр приставкаҳо, ҳатто онҳое, ки бо протсессори 64-битӣ кор мекунанд, рух медиҳад). Агар шумо боварӣ надоред – умумӣ OMP-<версия>.apk.
  6. APK-ро аз навтарин нашри GitHub зеркашӣ кунед, онро дар папкаи platform-tools ҷойгир кунед ва насб кунед: adb install -r OMP-<версия>-arm64.apk. Калид -r нусхаи навро ба ҷои нусхаи кӯҳна насб мекунад ва маълумоти шуморо нигоҳ медорад. Ҷавоб Success – тамом.

Android 11 ва навтар бидуни 'Тробиҳанди шабака': 'Тробиҳанди бесим' → 'Пайваст кардани дастгоҳ бо код', сипас adb pair <IP>:<порт> бо истифода аз рамзи ин равзана ва adb connect <IP>:<порт> порти нишондодашуда дар экрани 'Wireless Debugging'.

Хатоҳои маъмул

  • unauthorized - Дебаггинг тасдиқ нашудааст: экрани дастгоҳро кушоед ва «Иҷозат додан»-ро ламс кунед.
  • offline - пайвастшавӣ гум шуд: adb kill-server, сипас adb connect ё кабелро дубора пайваст кунед.
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE - OMP бо имзои дигар аллакай насб шудааст. Нусхаи эҳтиётиро дар OMP захира кунед ('Танзимот' → 'Advanced' → 'Backup'), OMP-и кӯҳнаро нест кунед (маълумоти он дар дастгоҳ, аз ҷумла TorrServer дар телефон бо таърихаш, ҳазф мешавад) ва онро дубора насб кунед.
  • INSTALL_FAILED_INSUFFICIENT_STORAGE - Ҷойи кофӣ барои нигаҳдорӣ нест: ҷойеро холӣ кунед.
  • INSTALL_FAILED_NO_MATCHING_ABIS - APK бо ин система мувофиқ нест: версияи armv7 ё универсалиро истифода баред.

Пас аз насб, агар дигар ба он ниёз надоред, режими ислоҳсозиро хомӯш кунед.

Оё OMP ройгон аст?

+-

Бале: плеер, идоракунии дурдаст, ҷустуҷӯ дар сарчашмаҳои шахсии шумо ва обунаҳои ҷараёни торрент бепул ва бидуни таблиғот кор мекунанд. Танҳо «Обунаи OMP» пулакӣ аст – он Jackett ва JacRed-ро дар сервери OMP пешакӣ танзимшуда пешниҳод мекунад, агар шумо нахоҳед Jackett-и худро танзим кунед. Шумо метавонед тавассути бот ё дар барнома пардохт кунед: бо корти бонкӣ, ҳамёни электронӣ, Telegram Stars ё криптовалюта (USDT, TON, BTC). Дар он ҷо истинод ба ҳисоби шумо низ дастрас аст. обуна ва код дар бот @OMPBILLINGBOT дастрасанд.
