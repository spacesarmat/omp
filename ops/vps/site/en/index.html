QUESTIONS

OMP questions, answered

What is OMP?

+-

OMP (Open Movie Player) is a free, open-source media player for LG webOS TVs, Android TV and Android phones. It plays movies and series from TorrServer on your home network, and your phone is the remote and a second screen. Ad-free with a subscription.

How do I watch torrents on my TV?

+-

TorrServer fetches a torrent piece by piece and streams the video over your network, so a movie starts before the download is complete. Install OMP on the TV, connect TorrServer and pick a movie or an episode on your phone.

Do I need a separate TorrServer?

+-

Not necessarily. On an arm64 Android phone, OMP downloads TorrServer from GitHub and runs it for you. The phone, the TV and the server must be on the same Wi-Fi network.

Which TVs and boxes are supported?

+-

LG TVs on webOS 4.0 or later (roughly 2018 and newer, no root needed), and Android TV and Google TV on Android 8 or later. Xiaomi, Sber and Yandex boxes take the same APK. Samsung (Tizen) is not supported yet.

How do I install OMP?

+-

The easiest way is from the phone: Settings, “Install OMP on the TV”. The phone finds LG and Android TV devices on the network and installs OMP itself. Files for a manual install are in the latest GitHub release: for Android there are three APKs - arm64 (almost all phones), armv7 (many TV boxes) and the universal one if you are not sure. For Windows, download the OMP-0.20.12-beta.2-setup.exe installer from the beta release and run it. From a computer, install the APK with ADB - steps below; for LG see the install guide.

How do I install OMP on Android with ADB?

+-

ADB installs OMP from a computer on an Android phone, Android TV, Google TV or a TV box. You need a computer with Windows, macOS or Linux and a USB cable (phone) or the same Wi-Fi network as the box (TV).

  1. Turn on developer mode: press “Build number” 7 times (phone: Settings, “About phone”) or “Build” (TV: Settings, System or Device Preferences, About).
  2. In “Developer options” turn on “USB debugging” and connect the phone by cable. On the TV turn on “Network debugging” and find the box IP in the network settings.
  3. Download Google platform-tools for your system, unpack the archive and open a terminal in the platform-tools folder. On macOS and Linux type ./adb instead of adb.
  4. For a TV first: adb connect <IP>:5555. Check the link: adb devices - the device must say device. On the device screen tick “Always allow from this computer” and choose “Allow”.
  5. Find the architecture: adb shell getprop ro.product.cpu.abi. The answer arm64-v8a - the file OMP-<version>-arm64.apk, armeabi-v7a - OMP-<version>-armv7.apk (many boxes say this even with a 64-bit processor). Not sure - the universal OMP-<version>.apk.
  6. Download the APK from the latest GitHub release, put it in the platform-tools folder and install: adb install -r OMP-<version>-arm64.apk. The -r flag installs over the old version and keeps the data. Success means it is done.

Android 11 and newer without “Network debugging”: “Wireless debugging”, “Pair device with pairing code”, then adb pair <IP>:<port> with the code from that window and adb connect <IP>:<port> with the port from the “Wireless debugging” screen.

Common errors

  • unauthorized - debugging was not confirmed: unlock the device screen and choose “Allow”.
  • offline - the link is lost: adb kill-server, then adb connect again or reconnect the cable.
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE - OMP with a different signature is already installed. Save a backup in OMP (Settings, “Advanced”, “Backup”), uninstall the old OMP (its data on the device is erased, including the TorrServer on the phone with its history) and install again.
  • INSTALL_FAILED_INSUFFICIENT_STORAGE - not enough space: free some memory.
  • INSTALL_FAILED_NO_MATCHING_ABIS - the APK does not fit this system: take armv7 or the universal one.

After the install, turn debugging off if you no longer need it.
