СУРООЛОР

OMP боюнча көп берилүүчү суроолор

OMP деген эмне?

+-

OMP (Open Movie Player) – LG webOS жана Android TV телевизорлору, ошондой эле Android телефондору үчүн акысыз, ачык булактуу медиа ойноткуч. Ал TorrServerден үй тармагыңыз аркылуу фильмдерди жана телесериалдарды агым катары көрсөтөт, ал эми телефонуңуз пульт жана экинчи экран катары кызмат кылат. Жарнамасыз жазылуу менен.

Телевизорумда торренттерди кантип көрсө болот?

+-

TorrServer торрентти бөлүктөр менен жүктөп, тармак аркылуу видеону дароо агым катары жиберет, ошондуктан фильм толук жүктөлбөй жатып эле ойной баштайт. Телевизоруңузга OMP орнотуп, TorrServerге туташып, телефонуңуздан фильмди же серияны тандаңыз.

Мага өзүнчө TorrServer керекпи?

+-

Мүмкүн болбосо да. arm64 архитектуралуу Android телефонуңузда OMP автоматтык түрдө GitHubтан TorrServerди жүктөп алып, иштетет. Телефонуңуз, телевизоруңуз жана сервериңиз бир эле Wi-Fi тармагында болушу керек.

Кайсы телевизорлор жана приставкалар колдоого алынат?

+-

webOS 4.0 жана андан кийинки (болжол менен 2018-жылдан тартып; root кирүүсү талап кылынбайт) LG телевизорлору, Android 8 жана андан кийинки версиядагы Android TV жана Google TV. Компьютерлер: Windows 10/11, macOS (Intel жана Apple Silicon) жана Linux. Xiaomi, Sber жана Yandex приставкалары бирдей APK аркылуу орнотулат. Samsung (Tizen) азырынча колдоого алынбайт.

OMPди кантип орнотом?

+-

Эң оңой ыкма – телефонуңуздан: «Параметрлер» → «TVге OMP орнотуу» – телефонуңуз тармактагы LG же Android TV түзмөгүн таап, OMPти автоматтык түрдө орнотот. Колу менен орнотуу үчүн файлдарды GitHubтагы акыркы чыгарылыштан таба аласыз: Android үчүн үч APK бар – arm64 (дээрлик бардык телефондордо), armv7 (көптөгөн приставкаларда) жана эгер кайсыны тандаарыңызды билбесеңиз, жалпысынан колдонулуучу версия. Windows үчүн орнотуучу программаны же портативдүү версияны жүктөп алыңыз. macOS үчүн Apple Silicon же Intel DMG файлын жүктөп алыңыз; Linux үчүн AppImage же deb пакетин жүктөп алыңыз. Apple кол тамгасы жок macOS үчүн: тиркемени чычкандын оң баскычы менен чыкылдатып, «Ачуу» пунктун тандаңыз же Терминалда: xattr -d com.apple.quarantine "/Applications/OMP.app"Компьютерде APK файлдары ADB аркылуу орнотулат – төмөнкү кадамдарга караңыз; LG түзмөктөрү үчүн GitHubтагы нускамаларды аткарыңыз.

ADB аркылуу Androidге OMPти кантип орнотуп коюуга болот?

+-

ADB OMPти компьютерден Android телефонуна, Android TVге, Google TVге жана set-top boxторго орнотот. Сизге Windows, macOS же Linux иштеп жаткан компьютер жана USB кабели (телефон үчүн) же set-top box менен биргелешкен Wi-Fi тармагы (TV үчүн) керек болот.

  1. Өнүгүүчү режимин күйгүзүңүз: «Куруу номерин» жети жолу басыңыз (телефон: «Параметрлер» → «Телефон тууралуу») же «Куруу» (телевизор: «Параметрлер» → «Система» же «Жабдык параметрлери» → «Жабдык тууралуу»).
  2. «Өнүгүүчүлөр үчүн» бөлүмүндө «USB-дебагдоону» күйгүзүп, телефонуңузду кабель аркылуу туташтырыңыз. Телевизордо «Тармак дебагдоону» күйгүзүп, тармак жөндөөлөрүнөн приставканын IP-дарегин табыңыз.
  3. Сиздин операциялык тутум үчүн Google'дун platform-tools пакетин жүктөп алып, архивди ачып, platform-tools папкасында терминалды ачыңыз. macOS жана Linuxта төмөнкү буйрукту териңиз ./adb ордуна adb.
  4. Телевизор үчүн, биринчи: adb connect <IP>:5555. Байланышты текшериңиз: adb devices - түзмөктүн жанында « device. Жабдуунун экранында «Ар дайым ушул компьютерден уруксат берүү» пунктун белгилеп, «Уруксат берүү» баскычын басыңыз.
  5. Архитектурасын аныктаңыз: adb shell getprop ro.product.cpu.abi. Жооп arm64-v8a - файл OMP-<версия>-arm64.apk, armeabi-v7a - OMP-<версия>-armv7.apk (бул көптөгөн set-top box түзмөктөрүндө, ал тургай 64-биттик процессору барларында да көп кездешет). Эгер так билбесеңиз, жалпы OMP-<версия>.apk.
  6. GitHub'дагы акыркы чыгарылыштан APK файлын жүктөп алып, platform-tools папкасына коюп, орнотуңуз: adb install -r OMP-<версия>-arm64.apk. Ачкыч -r жаңы версияны эски версиянын үстүнө орнотуп, маалыматтарыңызды сактайт. Жооп Success – болду.

Android 11 жана андан жаңыраак версияларда «Тармактык отладка» жок болсо: «Сымсыз отладка» → «Коду менен түзмөктү туташтыруу», андан соң adb pair <IP>:<порт> бул терезедеги кодду колдонуп жана adb connect <IP>:<порт> «Wireless Debugging» экранында көрсөтүлгөн порт.

Көп кездешүүчү каталар

  • unauthorized - Дебагдоо тастыкталган жок: түзмөктүн экранын ачып, «Уруксат берүү» баскычын тийип коюңуз.
  • offline - туташуу үзүлдү: adb kill-server, андан кийин adb connect же кабелди кайра туташтырыңыз.
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE - Башка кол коюлган OMP буга чейин орнотулган. OMPде резервдик көчүрмөнү сактаңыз («Параметрлер» → 'Advanced' → 'Backup'), эски OMPти өчүрүп (анын түзмөктөгү маалыматтары, анын ичинде телефондогу TorrServer жана анын тарыхы өчүрүлөт) кайра орнотуңуз.
  • INSTALL_FAILED_INSUFFICIENT_STORAGE - Сактагыч орун жетишсиз: бош орун бошотуңуз.
  • INSTALL_FAILED_NO_MATCHING_ABIS - APK бул система менен шайкеш келбейт: armv7 версиясын же универсалдуу версиясын колдонуңуз.

Орнотулгандан кийин, эгерде ага муктаж болбосоңуз, отладканы өчүрүңүз.

OMP акысызбы?

+-

Ооба: плеер, алыстан башкаруу, өз булактарыңызды жана торрент агымына жазылууларды изилдөө акысыз жана жарнамасыз иштейт. Болгону «OMP жазылуусу» акы төлөнөт – ал OMP серверинде алдын ала орнотулган Jackett жана JacRedди камсыздайт, эгерде сиз өз Jackettти орноткуңуз келбесе. Төлөмдү бот аркылуу же тиркемеде жүргүзө аласыз: карта, электрондук капчык, Telegram Stars же криптовалюта (USDT, TON, BTC) аркылуу. Аккаунтуңузга шилтеме да ошол жерде бар.
