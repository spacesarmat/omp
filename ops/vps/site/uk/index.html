ПИТАННЯ

Поширені запитання про OMP

Що таке OMP?

+-

OMP (Open Movie Player) — безкоштовний медіаплеєр з відкритим кодом для телевізорів LG webOS, Android TV та телефонів Android. Він показує фільми та серіали з TorrServer у домашній мережі, а телефон слугує пультом і другим екраном. З підпискою без реклами.

Як дивитися торренти на телевізорі?

+-

TorrServer завантажує файл частинами й одразу передає відео через мережу, тому фільм починається ще до повного завантаження. Встановіть OMP на телевізор, підключіть TorrServer і виберіть фільм або серію на телефоні.

Чи потрібен окремий TorrServer?

+-

Не обов’язково. На телефоні Android з arm64 OMP самостійно завантажить TorrServer з GitHub і запустить його. Телефон, телевізор і сервер мають бути в одній мережі Wi-Fi.

Які телевізори та приставки підтримуються?

+-

LG на webOS 4.0 і новіших версіях (приблизно з 2018 року, root не потрібен), Android TV і Google TV на Android 8 і новіших версіях. Комп’ютер: Windows 10/11, macOS (Intel та Apple Silicon) і Linux. Приставки Xiaomi, Сбер та Яндекс встановлюються тим самим APK. Samsung (Tizen) поки що не підтримується.

Як встановити OMP?

+-

Найпростіше з телефону: «Налаштування» → «Встановити OMP на телевізор» — телефон знайде LG або Android TV у мережі та встановить OMP самостійно. Файли для ручного встановлення містяться в останньому випуску на GitHub: для Android — три APK-файли — arm64 (майже всі телефони), armv7 (багато приставок) та загальний, якщо не впевнені. Для Windows завантажте інсталятор або портативну версію. Для macOS — DMG для Apple Silicon або Intel, для Linux — AppImage або deb. macOS без підпису Apple: клацніть правою кнопкою миші на програмі та виберіть «Відкрити», або в Терміналі: xattr -d com.apple.quarantine "/Applications/OMP.app". З комп’ютера APK встановлюється через ADB — кроки наведено нижче, для LG — інструкція на GitHub.

Як встановити OMP на Android через ADB?

+-

ADB встановлює OMP з комп’ютера на телефон Android, Android TV, Google TV та приставки. Потрібні комп’ютер із Windows, macOS або Linux та USB-кабель (телефон) або спільна мережа Wi-Fi з приставкою (ТВ).

  1. Увімкніть режим розробника: 7 разів натисніть «Номер збірки» (телефон: «Налаштування» → «Про телефон») або «Збірка» (ТВ: «Налаштування» → «Система» або «Налаштування пристрою» → «Про пристрій»).
  2. У розділі «Для розробників» увімкніть «Налагодження через USB» і підключіть телефон кабелем. На телевізорі увімкніть «Налагодження через мережу» і дізнайтеся IP-адресу приставки в налаштуваннях мережі.
  3. Завантажте platform-tools від Google для своєї системи, розпакуйте архів і відкрийте термінал у папці platform-tools. У macOS та Linux введіть ./adb замість adb.
  4. Для телевізора спочатку: adb connect <IP>:5555. Перевірте з’єднання: adb devices - поруч із пристроєм має бути позначка device. На екрані пристрою позначте «Завжди дозволяти з цього комп’ютера» та натисніть «Дозволити».
  5. Дізнайтеся архітектуру: adb shell getprop ro.product.cpu.abi. Відповідь arm64-v8a - файл OMP-<версія>-arm64.apk, armeabi-v7a - OMP-<версія>-armv7.apk (так буває на багатьох приставках навіть із 64-бітним процесором). Не впевнені — загальний OMP-<версія>.apk.
  6. Завантажте APK з останнього випуску на GitHub, помістіть у папку platform-tools та встановіть: adb install -r OMP-<версія>-arm64.apk. Ключ -r встановлює нову версію поверх старої та зберігає дані. Відповідь Success — готово.

Android 11 і новіші версії без «Налагодження через мережу»: «Бездротове налагодження» → «Підключити пристрій за кодом», потім adb pair <IP>:<порт> за допомогою коду з цього вікна та adb connect <IP>:<порт> з портом з екрана «Бездротове налагодження».

Поширені помилки

  • unauthorized - налагодження не підтверджено: розблокуйте екран пристрою та натисніть «Дозволити».
  • offline - зв'язок втрачено: adb kill-server, потім знову adb connect або перепідключіть кабель.
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE - вже встановлено OMP з іншим підписом. Збережіть резервну копію в OMP («Налаштування» → «Розширені» → «Резервна копія»), видаліть старий OMP (його дані на пристрої будуть видалені, зокрема TorrServer на телефоні з історією) та встановіть заново.
  • INSTALL_FAILED_INSUFFICIENT_STORAGE - не вистачає місця: звільніть пам'ять.
  • INSTALL_FAILED_NO_MATCHING_ABIS - APK не підходить для цієї системи: візьміть armv7 або універсальний.

Після встановлення вимкніть налагодження, якщо воно більше не потрібне.

OMP безкоштовний?

+-

Так: плеєр, пульт, пошук за власними джерелами та підписки на роздачі працюють без оплати й без реклами. Платна лише «Підписка OMP» — готові Jackett і JacRed на сервері OMP, якщо не хочеться встановлювати власний Jackett. Оплатити можна в боті та в додатку: карткою, гаманцем, зірками Telegram та криптовалютою (USDT, TON, BTC). Посилання на рахунок відкривається там само. Підписка та код — у боті @OMPBILLINGBOT.
