# Изменения

## 0.6.0

- Проверка обновлений при запуске и окно «Доступна версия»
- Экран «Обновление»: в один клик (root), через Homebrew Channel, с компьютера по QR-коду
- Репозиторий OMP для Homebrew Channel — добавляется одной кнопкой из Настроек
- Параметры запуска: play, torrent, magnet, server

## 0.5.0

- Экран входа с историей серверов и правкой логина и пароля
- Каталог: 4 вида карточек, вкладка «История», поиск, сортировка, значки качества
- Избранные плейлисты, смена сервера в Настройках

## 0.4.0

- Новое имя OMP, логотип и значки интерфейса
- Пауза по клику, перемотка двойным кликом у краёв экрана
