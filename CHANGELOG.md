## Не выпущено

- [phone] «Мои»: разные фильмы больше не склеиваются в одну карточку из-за года, качества или тегов в названии (Supergirl, «Звездный сигнал» и «Миньоны и монстры» снова отдельно); раздачи с разными фильмами TMDB никогда не объединяются, подсказка «Такая раздача уже есть» тоже точнее
- [phone] Экран фильма с несколькими раздачами: вместо строки «Раздача: ... · Сменить» блок «Раздачи (N)» - у каждой раздачи качество, размер и сиды, текущая отмечена, нажатие переключает; «Файлы» ниже относятся к выбранной раздаче

- [tech] Панель billing: вкладка «Мониторинг» с таблицей проверок (зелёный или красный статус, время, история за 7 дней) и кнопкой «Проверить сейчас»
- [tech] Проверки раз в 15 минут (интервал меняется во вкладке): все трекеры Jackett и JacRed напрямую и через WARP, поиск через Jackett, Cloudflare trace через WARP, Postgres, бэкап, опрос бота, диск, 4 публичных сайта, Jackett, JacRed и TorrServer во внутренней сети
- [tech] Контейнеры, перезапуски и память через прокси Docker только для чтения (новый контейнер omp-docker-proxy); перезапускать из панели нельзя
- [tech] Алерт в Telegram через @OMPBILLINGBOT только после повторной проверки через 30 с, один раз на проблему, и сообщение «починилось»
- [tech] Мониторинг: проверка сайтов (публичных и трекеров) засчитывается по коду ответа и заголовкам, без загрузки всей страницы, поэтому медленная загрузка тела больше не даёт ложный таймаут
- [tech] Мониторинг: сначала красное, полностью зелёные группы свёрнуты в одну строку («Контейнеры 12/12»); фильтр «Все / Только ошибки / Без алерта», поиск по названию, сортировка по статусу, названию, времени ответа и времени проверки; выбор запоминается в браузере
- [tech] Мониторинг: кнопка «Перепроверить все ошибки» запускает заново только красные проверки
- [tech] ops/vps/deploy.sh работает на NUC: docker compose с docker-compose.nuc.yml, проверки здоровья по http на порту 80, node --check в контейнере, если на хосте нет node
- [tech] JacRed: синхронизация базы с sync.jacred.stream идёт через WARP (globalproxy в jacred/init.yaml): прямой путь с NUC обрывался, и база 15 часов не пополнялась
- [tech] Мониторинг: кнопка «Перепроверить» у красной строки (только эта проверка), ход проверки «Проверка идёт: N из M» со временем начала, состояние каждой строки (проверяется, ждёт повтора, готово) и итог после конца
- [tech] JacRed на NUC: полный рабочий конфиг закреплён в jacred/init.yaml на хосте (вместе с globalproxy через WARP); в README описано, что настоящий конфиг это /app/init.yaml и что сохранение в админке JacRed нужно копировать на хост
- [tech] JacRed на NUC: таймер systemd раз в минуту копирует рабочий конфиг из контейнера на хост (с проверкой и резервной копией, последние 20), так что сохранение в админке JacRed переживает перезапуск
- [tech] Мониторинг: жёлтый статус «Просит код» для сайтов трекеров, которые отвечают капчей или проверкой на робота: без алерта, не считается ошибкой, свой фильтр, в сводке группы «12/12, 1 жёлтая»; если трекер был красным, алерт закрывается с пометкой «просит код»
- [tech] Мониторинг: если сайт трекера не отдаёт промежуточный сертификат, проверка докачивает его по AIA, как браузер, и проверяет цепочку полностью («сертификат докачан»); torrent.by больше не красный из-за «ошибки TLS»
