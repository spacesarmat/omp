# Сообщения об уязвимостях

## Поддерживаемые версии

Поддерживаются только два выпуска:

- последний стабильный релиз, сейчас [v0.30.0](https://github.com/spacesarmat/omp/releases/tag/v0.30.0)
- текущая бета, сейчас [v0.30.1-beta.3](https://github.com/spacesarmat/omp/releases/tag/v0.30.1-beta.3)

Более ранние релизы и предыдущие беты не поддерживаются. Когда выходит новый стабильный релиз или более новая бета, поддержка переходит на них.

## Куда писать

Уязвимость сообщается через закрытую форму GitHub Private vulnerability reporting:

https://github.com/spacesarmat/omp/security/advisories/new

Публичный issue, обсуждение, pull request и коммит для этого не используются. В сообщении достаточно версии, шагов воспроизведения и эффекта. Готовый публичный пример эксплуатации не нужен.

## Срок ответа

Обычный ориентир: подтверждение получения в течение нескольких дней и первая оценка в течение примерно недели. Это ожидание, а не обязательство по сроку. Исправление зависит от серьезности и объема правки. Критичные сообщения разбираются раньше остальных. Точный день исправления заранее не назначается.

## English

Supported releases are the latest stable (currently v0.30.0) and the current beta (currently v0.30.1-beta.3). Older releases are not supported. Support moves on when a newer stable or beta tag is published.

Report a vulnerability through GitHub private vulnerability reporting:

https://github.com/spacesarmat/omp/security/advisories/new

Do not open a public issue. A typical report is acknowledged within a few days, with a first assessment within about a week. That is an expectation, not a commitment. Fix time depends on severity and is not scheduled in advance.
