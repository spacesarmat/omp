# Приемник ИК-кнопок OMP

Маленькая прошивка для ESP32 или ESP8266 с приемником TSOP (например VS1838) на GPIO 14. Она записывает сырые длительности импульсов и отдает их телефону по сети.

Лицензия прошивки - GPL-3.0, как и OMP. Это свой код, не копия IRDB и не копия Flipper-IRDB.

## Что делает

- Точка в коде: впишите `WIFI_SSID` и `WIFI_PASS` в начале скетча.
- mDNS: служба `_omp-ir._tcp`, имя `omp-ir`.
- `POST /api/pair` - первый вызов выдает токен. Дальше нужен заголовок `Authorization: Bearer <токен>`.
- `GET /api/capture` - последний принятый код `{ "frequency": 0, "pulses": [...] }`. Пока кнопки не было, ответ 204. Частота 0: приемник не измеряет несущую, телефон подставляет 38 кГц.
- WebSocket `GET /ws` с тем же заголовком: при приеме кнопки уходит один текстовый кадр с тем же JSON.

Телефон находит приемник сам и сохраняет токен в хранилище ключей Android.
