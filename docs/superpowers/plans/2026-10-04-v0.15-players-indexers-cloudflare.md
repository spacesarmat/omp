# v0.15 «Плеер VLC, Jackett и сайты за Cloudflare» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Android TV gets an FFmpeg-enabled Media3 player plus libVLC as a second engine with «Авто» fallback; OMP talks to Jackett/Prowlarr directly (search, discovery, tracker status) with TorrServer as fallback; built-in Cloudflare pass (hidden WebView, interactive check on phone/TV, FlareSolverr fallback); five Cloudflare sites return; per-ABI APKs; every release build is posted to Telegram.

**Architecture:** Kotlin `PlayerEngine` interface with Media3 and VLC implementations behind the existing player UI. A new `indexer` source kind in `src/sources/` using native HTTP. A native `CloudflareSolver` layered under `SiteHttp`, with a FlareSolverr client and a phone↔TV «solve on phone» message over the existing ControlServer pairing. New site parsers follow the existing `src/sources/*.ts` pattern.

**Tech Stack:** Preact + TypeScript (src/, mobile/), Kotlin (android/), Media3 1.8, libVLC (org.videolan.android), Vitest, JUnit.

**Spec:** `docs/superpowers/specs/2026-10-04-v0.15-players-indexers-cloudflare-design.md` (binding; Russian copy verbatim). Mockups: https://claude.ai/artifact/BADUX6eszgncQBGn2HqSYg (local copies: scratchpad `omp-v015/project/*.dc.html`).

## Global Constraints

- TV code (`src/`) Chromium 53 rules (no Error subclassing, no AbortController, no CSS grid / flex `gap` / `inset`, regex without `u`/lookbehind), no `@capacitor` imports in `src/`, no `src/`→`mobile/` imports; new parsers/indexers stay out of the LG bundle (lazy, Android-only).
- Dependency licenses must be compatible with OMP's own GPL-3.0-only: Jellyfin media3-ffmpeg-decoder (GPL-3.0) and libVLC (LGPL-2.1) are fine; new libraries listed in README «Лицензия».
- Site passwords, indexer API keys, Cloudflare cookies: memory or Android encrypted storage only — never logs (incl. logcat), localStorage, backups, TorrServer journal, test snapshots.
- Requests only to addresses the user set or OMP found on the LAN (sites, their Jackett/Prowlarr/FlareSolverr, TorrServer); no third-party solving services. No CAPTCHA solving — interactive checks are shown to the user.
- Mobile Android 8+ / WebView Chrome 90+. UI text Russian only. localStorage keys `tsp.*` via loadJson + sanitizer.
- Vitest: no global mocks/setup files; run from repo root; exit 0, no unhandled errors. Network in tests: fakes/fixtures only; fixture pages use fictional titles.
- Commits: Conventional, subject only. NO Co-Authored-By / co-author / AI lines.
- If `npm run android:debug` changes `android/*.gradle` only in line endings, restore them before committing.
- Full checks per task: `npx vitest run`, `npx tsc --noEmit -p .`, `npx tsc --noEmit -p mobile`, `npm run build`, `npm run check:boot`, `npm run build:mobile`; Kotlin tasks also `npm run android:debug` + `node scripts/gradle.mjs testDebugUnitTest`.
