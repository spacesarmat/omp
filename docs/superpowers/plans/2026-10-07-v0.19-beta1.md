# OMP 0.19.0-beta.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Filmography of cast and directors (phone + TV) and 2160 Player as an alternative video player via its Intent API (Android phone + Android TV).

**Architecture:** TMDB person data and pure filmography helpers live in `src/catalog/` (shared by phone, LG, Android TV). Each platform gets a «Человек» screen and clickable people on title cards, series screens and movie torrent screens. 2160 Player is launched by an explicit-component Intent from a restored and reworked `ExternalPlayer.kt`; TV and phone pick it by a new setting and save the returned position like the built-in player.

**Tech Stack:** Preact + signals (TV: norigin spatial navigation, Chromium 53 safe ES5-compatible code), Capacitor phone app, Kotlin (Android), vitest, JUnit.

**Spec:** `docs/superpowers/specs/2026-10-07-v0.19-beta1-design.md`

## Global Constraints

- TV code runs on LG webOS Chromium 53: no optional chaining at runtime targets beyond what the existing build transpiles; follow existing TV code style (functions, `tvGlyphs` around visible strings).
- Every visible string goes through `t()`; add keys to both `src/i18n/ru.ts` and `src/i18n/en.ts`; English strings have no Cyrillic.
- Focus keys: groups UPPERCASE (`PERSON-GRID`), items lowercase-dashed (`person-tile-movie-123`).
- No biography on the person screen.
- Talk/news/reality excluded from filmographies: genre ids `10763, 10764, 10767` (`TV_EXCLUDED` in `src/catalog/discoverQuery.ts`).
- Cast shown: up to 15 actors, plus directors (movies, `crew` with `job === 'Director'`) or creators (TV, `created_by`), people first.
- Titles already in «Мои»: accent border + «В медиатеке», always sorted first; press opens them in «Мои».
- 2160 Player packages: `tv.p2160.player`, then `tv.p2160.player.debug`; activity `tv.p2160.core.Player2160Activity`. Explicit component, no chooser.
- 2160 extras: `title`, `position` (Int ms), `from_start` (Boolean), `tv.p2160.extra.SEGMENTS` (`intro:<ms>-<ms>;credits:<ms>-`), `video_list` (Uri[]), `video_list.name` (String[]), `return_result=true`. Result: `data` (Uri), `position`/`duration` (Int ms; fallback `extra_position`/`extra_duration` Long), `end_by` (`playback_completion` = watched).
- Release link: `https://github.com/spacesarmat/2160player/releases/latest`.
- Changelog markers: `[phone]`, `[tv]` (both TVs), `[lg]`, `[atv]`; CHANGELOG.en.md has no Cyrillic.
- No Co-Authored-By or AI lines in commits.

`filmography.ts`:

```ts
import type { CatalogTitle } from './tmdb';
import type { Credit, PersonCard } from './tmdb';
import { TV_EXCLUDED } from './discoverQuery';
export type FilmSort = 'popular' | 'year';
export function filmography(p: PersonCard, job: 'acting' | 'directing', sort: FilmSort, owned: (c: CatalogTitle) => boolean, onlyOwned: boolean): { credit: Credit; owned: boolean }[] {
  const list = (job === 'acting' ? p.acting : p.directing)
    .filter((c) => !c.genreIds.some((g) => TV_EXCLUDED.indexOf(g) >= 0))
    .map((c) => ({ credit: c, owned: owned(c) }))
    .filter((x) => !onlyOwned || x.owned);
  const key = (x: { credit: Credit }) => (sort === 'year' ? x.credit.date || '' : '');
  return list.sort((a, b) => {
    if (a.owned !== b.owned) return a.owned ? -1 : 1;
    if (!a.credit.poster !== !b.credit.poster) return a.credit.poster ? -1 : 1;
    if (sort === 'year' && key(a) !== key(b)) return key(a) < key(b) ? 1 : -1;
    return (b.credit.popularity || 0) - (a.credit.popularity || 0);
  });
}
export function personJobs(p: PersonCard): ('acting' | 'directing')[] {
  const order: ('acting' | 'directing')[] = p.known === 'directing' ? ['directing', 'acting'] : ['acting', 'directing'];
  return order.filter((j) => (j === 'acting' ? p.acting : p.directing).length > 0);
}
```
