# OMP 0.16 Russian + English Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All OMP copy (phone, LG, Android TV, native Android, FAQ, «Что нового», README) in Russian and English with named keys, a language setting that follows the system by default, and the phone setting the TV's language; released as 0.16.0-beta.1.

**Architecture:** Typed dictionaries `src/i18n/ru.ts` / `src/i18n/en.ts`, a tiny runtime `src/i18n/index.ts` (`t`, `tp`, formatters, `lang` signal), a guard test that fails on Cyrillic copy outside the dictionaries (with a shrinking PENDING list during the migration), area-by-area migration tasks, a small Kotlin `I18n.kt` for native-only copy.

**Tech Stack:** TypeScript (template-literal key types), Preact signals, Vitest, Kotlin (Android).

**Spec:** `docs/superpowers/specs/2026-10-05-v0.16-i18n-design.md`

## Global Constraints

- Named keys only: `t('area.sub.key')`. No Russian string literals in UI code after migration (guard test).
- Dictionary groups (top-level keys): `common`, `connect`, `library`, `torrent`, `player`, `add`, `sources`, `cloudflare`, `monitor`, `news`, `remote`, `tv`, `settings`, `update`, `install`, `backup`, `log`, `donate`, `errors`, `notify`, `faq`, `whatsNew`, `server`, `catalog` (add a group only when none fits).
- Key names: lowerCamelCase, English, describe the meaning not the text (`settings.update.checkOnStart`, not `settings.proveryatObnovleniya`).
- Placeholders `{name}`; plurals: Russian `{ one, few, many }`, English `{ one, other }`.
- Language setting values `'system' | 'ru' | 'en'`; resolved language `'ru' | 'en'`; Russian for `ru`, `uk`, `be`, `kk`, English otherwise.
- `src/` code follows Chromium 53 rules (no `?.`, `??`, `Intl.PluralRules`, `Array.prototype.includes`, `flat`); `mobile/src/` may use modern syntax.
- English copy: plain, short, sentence case, same meaning as the Russian; product names unchanged (OMP, TorrServer, Jackett, Prowlarr, FlareSolverr, Kinozal, rutracker, rustorka, Homebrew Channel, Developer Mode).
- Tracker data and tracker-parsing patterns are not copy: they stay in code and go on the guard test's ALLOWLIST with a reason.
- Tests run in Russian (setup file); never change an existing Russian assertion to make a migration pass — if a test fails, the migration changed the text.
- Never add Co-Authored-By or AI attribution lines to commits.

```ts
import { describe, it, expect } from 'vitest';
// @ts-ignore node builtins
import { readdirSync, readFileSync, statSync } from 'node:fs';
// @ts-ignore
import { join } from 'node:path';

/** Files still to migrate (each migration task removes its own; Task 14 leaves it empty). */
const PENDING: string[] = [
  // filled in Step 3 with the output of the scan, sorted
];
/** Not copy: tracker parsers and patterns (reason each). */
const ALLOWLIST: { [file: string]: string } = {
  'src/i18n/ru.ts': 'the Russian dictionary',
  'mobile/src/faq.ru.ts': 'Russian FAQ texts',
};

function files(dir: string): string[] {
  const out: string[] = [];
  for (const n of readdirSync(dir)) {
    const p = join(dir, n);
    if (statSync(p).isDirectory()) out.push(...files(p));
    else if (/\.(ts|tsx)$/.test(n) && !/\.d\.ts$/.test(n)) out.push(p.replace(/\\/g, '/'));
  }
  return out;
}

/** Cyrillic in string/template literals or JSX text; comments are stripped first. */
export function russianCopy(src: string): string[] {
  const code = src.replace(/\/\*[\s\S]*?\*\//g, '').replace(/(^|[^:'"`])\/\/.*$/gm, '$1');
  const hits: string[] = [];
  const re = /(['"`])((?:\\.|(?!\1)[^\\\n])*[А-Яа-яЁё](?:\\.|(?!\1)[^\\\n])*)\1|>([^<>{}]*[А-Яа-яЁё][^<>{}]*)</g;
  let m: RegExpExecArray | null;
  while ((m = re.exec(code))) hits.push((m[2] || m[3]).trim());
  return hits;
}

describe('no Russian copy outside the dictionaries', () => {
  const all = files('src').concat(files('mobile/src'));
  it('every file with Russian copy is migrated, allowlisted or still pending', () => {
    const offenders = all.filter((f) => !ALLOWLIST[f] && PENDING.indexOf(f) < 0 && russianCopy(readFileSync(f, 'utf8')).length > 0);
    expect(offenders).toEqual([]);
  });
  it('PENDING lists only files that still have Russian copy', () => {
    const done = PENDING.filter((f) => all.indexOf(f) < 0 || russianCopy(readFileSync(f, 'utf8')).length === 0);
    expect(done).toEqual([]);
  });
});
```

```ts
type Join<P extends string, K extends string> = P extends '' ? K : `${P}.${K}`;
export type StringKeys<T, P extends string = ''> = { [K in keyof T & string]: T[K] extends string ? Join<P, K> : T[K] extends Plural ? never : StringKeys<T[K], Join<P, K>> }[keyof T & string];
```
