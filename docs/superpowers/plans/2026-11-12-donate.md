# Донат OMP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Принять донат любой суммы в боте и показать его в админке, не продлевая подписку.

**Architecture:** Модуль `ops/billing/src/donate.mjs` хранит черновик и оплату в коллекции `donations`. Вебхуки с меткой `don:` идут в `applyDonation`, остальные в `applyPayment`. Список благодарностей отдаёт `GET /v1/thanks` и рисуется на экране аккаунта.

**Tech Stack:** Node, Postgres, Preact, React admin.

**Spec:** `docs/superpowers/specs/2026-11-12-donate-design.md`
