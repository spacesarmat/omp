# v0.13 «Мониторинг» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Subscriptions, new-episode tracking with «Заменить», the «Новое» feed in a new fifth tab, background checks via a hidden WebView run by WorkManager, notifications with background actions.

**Spec:** `docs/superpowers/specs/2026-10-03-v0.13-monitoring-design.md` (binding; Russian copy verbatim). Mockups: https://claude.ai/artifact/1Hh8km52vnDxfeLgVYCB4a (local copies: scratchpad `omp-v013/project/*.dc.html`).

## Global Constraints

- TV code (`src/`) Chromium 53 rules (no Error subclassing, no AbortController, no CSS grid / flex `gap` / `inset`, regex without `u`/lookbehind), no `@capacitor` imports in `src/`. Shared monitor logic lives in `src/monitor/`.
- Mobile Android 8+ / WebView Chrome 90+. UI text Russian only. localStorage keys `tsp.*` via loadJson + sanitizer.
- Monitoring is phone-only (not Android TV, not LG).
- Tracker passwords and session cookies: Android encrypted storage only — never localStorage, logs, the TorrServer journal, or test snapshots.
- Journal: keys inside `omp` preserved (v0.12 rule); `s.w: false` = don't watch for new episodes.
- Vitest: no global mocks/setup files; run from repo root; must exit 0 with no unhandled errors. Network in tests: fixtures only.
- Commits: Conventional, subject only. NO Co-Authored-By / co-author / AI lines.
- If `npm run android:debug` changes `android/*.gradle` only in line endings, restore them before committing.
