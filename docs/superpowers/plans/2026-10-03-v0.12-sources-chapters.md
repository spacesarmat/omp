# v0.12 «Источники», «Главы и пропуски» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Chapters and intro/credits skipping on LG, Android TV and the phone remote; per-torrent skip settings in the torrent card; unified search over TorrServer and built-in tracker parsers on Android, with a «Источники поиска» screen and rutracker login.

**Spec:** `docs/superpowers/specs/2026-10-03-v0.12-sources-chapters-design.md` (binding; Russian copy verbatim). Mockups: https://claude.ai/artifact/7tACZSQiXdrW9azNnJJPxc (local copies: scratchpad `omp-v012/project/*.dc.html`).

## Global Constraints

- TV code (`src/`) Chromium 53 rules (no Error subclassing, no AbortController, no CSS grid / flex `gap` / `inset`, regex without `u`/lookbehind), no `@capacitor` imports in `src/`.
- Mobile Android 8+ / WebView Chrome 90+. UI text Russian only. localStorage keys `tsp.*` via loadJson + sanitizer.
- Skip settings: key `s` inside the journal object `omp` of the torrent `data`: `{ i: bool, c: bool, mi?: [start, end], mc?: seconds }`; journal version stays 1; writing history keeps `s`, writing `s` keeps history and every other `data` key; non-JSON `data` untouched.
- Tracker passwords and session cookies: Android encrypted storage only — never localStorage, logs, the TorrServer journal, or test snapshots.
- Built-in sources run on Android only (phone + Android TV); LG search stays TorrServer-only.
- Vitest: no global mocks/setup files; run from repo root; must exit 0 with no unhandled errors. Network in tests: fixtures only.
- Commits: Conventional, subject only. NO Co-Authored-By / co-author / AI lines.
- If `npm run android:debug` changes `android/*.gradle` only in line endings, restore them before committing.
