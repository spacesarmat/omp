# OMP 0.19.0-beta.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Polish the 0.19.0-beta.1 filmography by user feedback: person screen opens in «Обзор», biography (3–4 lines + «Ещё»), tidy person-screen style, «В ролях» right under the action buttons on series/movie screens in «Мои».

**Architecture:** Biography comes from the same TMDB `person/{id}` request (interface language, English fallback by a second cached request only when empty). TV and phone person screens get a one-row filter bar and a bio block; the cast row moves up on the TV and phone series/torrent screens.

**Tech Stack:** Preact (TV: Chromium 53 + norigin spatial nav; phone: Capacitor), vitest.

**Spec:** `docs/superpowers/specs/2026-10-07-v0.19-beta1-design.md` (amended by the decisions below — they override «Биография не показывается»).

## Global Constraints (decisions from the user, 2026-10-07)

- Pressing a person anywhere (incl. «Мои») opens the person screen **inside «Обзор»**: phone — the catalog header shows the «Мои / Обзор» switch with «Обзор» active and the «Каталог» tab active; «Назад» returns to the screen it came from. TV — the «Обзор» tab is highlighted in the header area of the person screen (or the screen sits under the library header with «Обзор» active).
- «В ролях» on series and movie screens in «Мои» goes **right under the action buttons** («Смотреть…»), before «Пропуск», «Мониторинг» and files — phone and TV — with the same side padding as other blocks.
- Biography: 3–4 lines under the header, «Ещё» expands in place (phone) / opens a dialog with the full text (TV). Interface language; if empty, English; if none, no block.
- Person screen style: header = large photo, name, job · years on one line, then bio; filters in ONE row: «Все / В медиатеке» segmented + one sort toggle «Популярные ↕ По году» (Discover's sort button style on the phone, `m-icon-btn m-sort` pattern); job switch (Актёр/Режиссёр) only when both, in the same row on TV, as a separate small segmented row on the phone only when needed. Tiles: role one grey line; «В медиатеке» mark in Discover style plus accent border.
- All visible strings via t(), ru + en (no Cyrillic in en); TV strings in tvGlyphs. Changelog markers [phone]/[tv]/[lg]/[atv].
- No Co-Authored-By or AI lines in commits.

### Task 1: Biography in PersonCard

**Files:** `src/catalog/tmdb.ts` (PersonCard + sanitizePerson), `src/catalog/client.ts` (person()), tests `tests/catalog/tmdb.test.ts`, `tests/catalog/client.test.ts`.

**Produces:** `PersonCard.bio: string` (trimmed TMDB `biography`). `client.person(id)` — when `bio` is empty and the interface language is not English, fetch `person/{id}` with `language=en-US` (no append), take its `biography`, cache both like other card requests (CARD_TTL); failure of the fallback keeps `bio: ''`.

- [ ] Tests: sanitizePerson keeps `biography` trimmed; client: ru empty bio → second request with en-US used, result `bio` from en; ru non-empty → no second request; fallback rejects → bio ''.
- [ ] Implement, run `npx vitest run tests/catalog`, commit `feat(catalog): person biography with an English fallback`.

### Task 2: TV — person screen in «Обзор», bio, one-row filters; cast under buttons

**Files:** `src/screens/Person.tsx`, `src/styles.css`, `src/ui/CastRow.tsx` (no behaviour change), `src/screens/Series.tsx`, `src/screens/Torrent.tsx`, `src/i18n/ru.ts`, `src/i18n/en.ts`, tests `tests/ui/personTv.test.tsx`, `tests/ui/seriesTv.test.tsx`, `tests/ui/torrentCast.test.tsx`.

- Person screen: header photo 220px, name, `job · years` line, bio clamped to 4 lines (`-webkit-line-clamp` works on Chromium 53) and a focusable «Ещё» button (`person-bio-more`) opening the existing dialog host (`src/ui/dialog`) with the full text, only when the text overflows or is longer than ~300 chars; one `PERSON-BAR` row: job segment (if both), «Все / В медиатеке», sort toggle button `person-sort` showing the current sort (OK switches). «Обзор» context: render the library TopBar-like breadcrumb is out of scope — instead show a small «Обзор ›» label above the name and keep Back → previous screen (ruling: TV header with tabs belongs to the library screen; a label is the consistent marker).
- Series/Torrent screens: move `CastRow` directly after the action buttons group (before skip/monitoring/files) with the same section padding as other sections; focus order follows layout.
- Tests: bio clamp + «Ещё» opens dialog with full text; no bio → no block; sort toggle switches popular↔year; cast group appears before the skip section in DOM order on series and torrent screens.
- [ ] Implement, run the touched tests + `tests/ui/tvEnglish.test.tsx`, commit `feat(tv): person biography, one-row filters, cast under the buttons`.
