# v0.7 «OMP для Android» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android-приложение OMP (Capacitor + общий код с ТВ). В нём каталог и раздачи, запуск на телевизоре LG по протоколу SSAP, пульт, добавление и поиск, внешний плеер, QR-перенос сервера с ТВ, самообновление APK. Плюс доработки ТВ: параметр запуска `file`/`t` и экран «Подключить телефон».

**Architecture:** Мобильный клиент лежит в `mobile/` и использует модули `src/api`, `src/lib`, `src/store` ТВ-приложения. Всё, чего нет в WebView, делает нативный плагин Capacitor `OmpNative` (Kotlin): SSDP-поиск ТВ, WebSocket к ТВ (ws/wss с самоподписанным сертификатом), внешний плеер, установка APK, приём magnet-ссылок. Протокол SSAP — чистый TypeScript (`mobile/src/tv/ssap.ts`) поверх транспорта плагина.

**Tech Stack:** Preact 11 + @preact/signals, TypeScript, Vite 8, Vitest + jsdom, Capacitor 8 (Android), Kotlin + OkHttp, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-02-v0.7-android-design.md`

## Global Constraints

- **ТВ-код (`src/`)** — Chromium 53:
  - не наследоваться от `Error`;
  - без `AbortController`;
  - без CSS grid, flex `gap` и `inset`;
  - регулярные выражения без флага `u` и без lookbehind.
- **Мобильный код (`mobile/`)** — Android 8+ (minSdk 26), WebView Chrome 90+. Современный CSS разрешён (grid, gap).
- **Интерфейс** — только на русском.
- **localStorage** — ключи `tsp.*`, чтение через `loadJson` и санитайзер.
- **Идентификаторы:** приложение Android `com.spacesarmat.omp`, ТВ-приложение `com.spacesarmat.torrplayer` (не менять).
- **Тесты** (Vitest) используют НАСТОЯЩУЮ библиотеку spatial navigation. Нельзя глобальные моки и setup-файлы. Нельзя трогать блок `test` в `vite.config.ts`, кроме добавления `mobile/tests/**` в `include`.
- **Коммиты** — Conventional Commits, ТОЛЬКО тема. Никаких `Co-Authored-By` и подписей ИИ — в коммитах, PR, документах.
- **Секреты.** Никаких ключей подписи, паролей и токенов в репозитории.
- **Ветка** `feat/v0.7-android`.
- **Проверки в конце каждой задачи:**

- [ ] **Step 3: `src/lib/pairing.ts`**
```ts
export interface PairData {
  url: string;
  name?: string;
  user?: string;
  password?: string;
}

const PREFIX = 'omp://pair?';
const FIELDS: (keyof PairData)[] = ['url', 'name', 'user', 'password'];

/** QR payload shown on the TV («Подключить телефон») and scanned by the phone. */
export function buildPairUri(d: PairData): string {
  let s = PREFIX + 'v=1';
  FIELDS.forEach((k) => {
    const v = d[k];
    if (v) s += '&' + k + '=' + encodeURIComponent(v);
  });
  return s;
}

export function parsePairUri(s: string): PairData | null {
  if (typeof s !== 'string' || s.indexOf(PREFIX) !== 0) return null;
  const out: { [k: string]: string } = {};
  let version = '';
  try {
    s.slice(PREFIX.length).split('&').forEach((part) => {
      const eq = part.indexOf('=');
      if (eq < 0) return;
      const k = part.slice(0, eq);
      const v = decodeURIComponent(part.slice(eq + 1));
      if (k === 'v') version = v;
      else if (FIELDS.indexOf(k as keyof PairData) >= 0 && v) out[k] = v;
    });
  } catch (e) {
    return null;
  }
  if (version !== '1' || !out.url) return null;
  return out as unknown as PairData;
}
```

## Шаг пользователя перед релизом (контроллер спрашивает перед выполнением)

Ключ подписи Android:
- создаётся `keytool -genkeypair` (RSA 4096, срок 30 лет) в папке ВНЕ репозитория;
- пароль генерируется;
- секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` записываются через `gh secret set`;
- путь к файлу ключа и пароль показываются пользователю один раз: их нужно сохранить, потеря ключа = невозможность обновлять приложение «поверх».

Без явного «да» пользователя ключ не создаётся и секреты не записываются.
