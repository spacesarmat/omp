# v0.14 «Надёжность, Android TV и помощник установки» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Android build + Kotlin tests in CI, a privacy-safe error log with GitHub reporting, Android TV parity (sources, rutracker login, send from phone, manual skip marks), settings backup, review leftovers, and a phone install assistant that detects the TV and installs OMP on LG (Developer Mode) and Android TV (adb).

**Spec:** `docs/superpowers/specs/2026-10-03-v0.14-reliability-atv-design.md` (binding; Russian copy verbatim). Mockups: https://claude.ai/artifact/DJ2PJVGjK7Yk15AMtUHtdS (local copies: scratchpad `omp-v014/project/*.dc.html`).

## Global Constraints

- TV code (`src/`) Chromium 53 rules (no Error subclassing, no AbortController, no CSS grid / flex `gap` / `inset`, regex without `u`/lookbehind), no `@capacitor` imports in `src/`.
- Mobile Android 8+ / WebView Chrome 90+. UI text Russian only. localStorage keys `tsp.*` via loadJson + sanitizer.
- Tracker passwords, session cookies, SSH keys, pairing codes: memory for the operation or Android encrypted storage only — never logs, localStorage, backups, the TorrServer journal or test snapshots.
- Error log contains no personal data (no passwords, cookies, server addresses, torrent titles, hashes, query strings).
- Vitest: no global mocks/setup files; run from repo root; must exit 0 with no unhandled errors. Network in tests: fakes/fixtures only.
- Commits: Conventional, subject only. NO Co-Authored-By / co-author / AI lines.
- If `npm run android:debug` changes `android/*.gradle` only in line endings, restore them before committing.
