# OMP 0.18.0-beta.2 (ТВ: «Обзор», карточка, «В лучшем качестве») Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the TV gets the «Обзор» tab (TMDB catalog with sort, filters and title search), a title card for films and series (hero, seasons, cast, «Найти раздачи», «Хочу посмотреть»), a TV-local «Хочу посмотреть» list, and the «В лучшем качестве» dialog on the torrent and series screens.

**Architecture:** reuse the shared TMDB client (`activeCatalog()` → `tvCatalog` on the TV), `src/catalog/discoverQuery.ts`, `src/catalog/library.ts` (`libraryIndex`/`inLibrary`), `torrentQuery`, and the shared upgrade/replace modules (`src/monitor/upgrade.ts`, `quality.ts`, `replace.ts`). TV UI is Preact + norigin spatial navigation, remote-first.

**Tech Stack:** Preact, @preact/signals, norigin-spatial-navigation, vitest + jsdom, TypeScript; TV bundle targets Chromium 53.

**Spec:** `docs/superpowers/specs/2026-10-06-v0.18-tv-design.md` (section «beta.2»). Mockups: https://claude.ai/artifact/VCR6KkWh79rmRvUMrHW2jL (artboards 3 «Обзор», 4 «Карточка фильма», 5 «В лучшем качестве»). ## Global Constraints

- TV code in `src/` runs on Chromium 53: no `?.`, no `??`, no `Array.prototype.flat/flatMap`, no `Object.fromEntries`, no `String.prototype.replaceAll`; CSS: no flex `gap` (margins; grid `gap` is fine), no `inset`, no `aspect-ratio`, no `position: sticky`.
- All user-visible copy through `t()` / `tp()` with keys in BOTH `src/i18n/ru.ts` and `src/i18n/en.ts`; reuse existing `discover.*`, `titleCard.*`, `catalog.*`, `torrent.better.*`, `monitor.replaceSheet.*` keys where the wording fits. No Cyrillic in `.ts/.tsx` outside the dictionaries (tests may contain Cyrillic fixtures). Text rendered on the TV from shared data must not contain glyphs the LG font lacks (U+2011 etc.) — use `tvGlyphs()` from `src/screens/Faq.tsx` (move it to a shared `src/ui/tvText.ts` if needed).
- The phone must keep working exactly as before: every test in `mobile/tests/` stays green.
- Commands: `npx vitest run`; `npx tsc --noEmit -p .`; `npx tsc --noEmit -p mobile`; `npm run build`; `npm run check:boot`.
- Commit messages in English, conventional, no co-author or AI lines. Branch `feat/v0.18-tv`.
- Test pattern: `tests/ui/seriesTv.test.tsx` (stub catalog via `setCatalogProvider(() => Promise.resolve(stub))`, mockFetch for `/torrents`, mount inside `act`, unmount in `afterEach`).

### Task 1: «Обзор» tab — grid, sort and filters, title search

**Files:** create `src/screens/library/DiscoverGrid.tsx`, `src/store/discover.ts` (TV query store, localStorage key `tsp.tvDiscoverQuery`, sanitized with `sanitizeDiscoverQuery`); modify `src/lib/libraryView.ts` (tab `discover` after `history`), `src/screens/Library.tsx` (branch for the discover tab), `src/ui/TopBar.tsx` (tab label `discover.browse`), `src/styles.css`, ru/en; tests `tests/ui/discoverTv.test.tsx`, update `tests/ui/topbar.test.tsx`.

Behaviour (mockup 3):
- Row under the header: kind switch «Всё / Фильмы / Сериалы» (three focusables, focus selects), then «Сортировка: …», «Жанр: …», «Год: …», «Страна: …», «Рейтинг: от N» — each opens `choose()` with the options from `discoverQuery.ts` (`DISCOVER_SORTS`, `GENRES` (multi-select is not needed on TV: one genre or «любой»), year presets any/this/last, `DISCOVER_COUNTRIES`, `DISCOVER_RATINGS`); right side «Найти фильм» → `askText` → TMDB `search(q,1)` results replace the grid with a «Результаты: q» heading and a «Сбросить поиск» button.
- Grid of posters, 8 per row, each tile: poster (TMDB image), rating badge «★ 7.8», marks «В медиатеке» (via `libraryIndex(torrents.value)` / `inLibrary`) and «Хочу» (Task 3 list), title (one line, ellipsis), meta «2025 · сериал».
- Paging: when focus reaches the last row, load the next page (`discover(kind, query, page+1)`), keep focus.
- Errors: `catalogErrorCode` → the same texts as the phone (`discover.offlineText`, `discover.nokeyText`) with a «Повторить» button.
- OK on a tile → route `{ name: 'title', kind, id }` (Task 2; this task adds the route type and a stub screen rendering `<div class="screen" />`). Yellow key on a tile toggles «Хочу» (Task 3; until then no-op).
- Hints: «ОК — карточка · жёлтая — хочу посмотреть · синяя — фильтры · Назад — к медиатеке» (blue opens the sort dialog).

- [ ] Tests: tab present after «История»; grid renders stub items with rating and «В медиатеке» mark; changing sort via `choose` re-queries `discover` with the new sort and persists it; search replaces the grid and «Сбросить поиск» restores; focus on last row loads page 2; offline error shows retry.
- [ ] Implement; vitest, tsc ×2, build, check:boot; commit `feat(tv): «Обзор» tab — TMDB catalog with sort, filters and search`.

### Task 4: «В лучшем качестве» on the TV

**Files:** create `src/ui/BetterDialog.tsx`; modify `src/screens/Torrent.tsx` (button in TORRENT-ACTIONS when `upgradeKind(...)` is not null), `src/screens/Series.tsx` (button in SERIES-ACTIONS for the chosen season; several members → `choose` which release to upgrade), `src/styles.css`, ru/en; move `failureOf` from `mobile/src/ui/BetterSheet.tsx` to a shared module (e.g. `src/monitor/upgradeText.ts`) and import it from both; tests `tests/ui/betterTv.test.tsx`.

Behaviour (mockup 5): a modal panel: title «В лучшем качестве», the current release line (quality label + size), a spinner «Ищем…» while `findUpgrades(tvSourceContext(), lib)` runs (LG: TorrServer rutor/torznab via `ctx.client`; Android TV: all sources), then rows (quality tags from `qualityLabel`, short name, size · seeds · source; low seeds warning via `isLowSeeds`; multi-season pack note via `seasonsCovered`), focus on the first row; OK on a row → confirm «Заменить?» with «Заменить» / «Добавить рядом» / «Отмена» (`choose`). «Заменить» → `replaceWithResult(...)` + `carryProgress(...)`, then `refreshTorrents()` and `replaceRoute({name:'torrent', hash:newHash})` (series screen: stay, refresh). «Добавить рядом» → add the torrent without removing the old one. Nothing found / errors → `failureOf` text. Back closes (and aborts the search via `replaceAbort`/abort signal). The «Следить за лучшим качеством» switch from the mockup is shown disabled with «в OMP на телефоне» (beta.4).
