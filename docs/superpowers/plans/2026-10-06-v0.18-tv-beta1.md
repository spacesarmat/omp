# OMP 0.18.0-beta.1 (ТВ: медиатека, экран сериала, переименование, справка) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the TV library shows short titles, one tile per series with its TMDB status, labelled header icons and a hint bar that never covers tiles; a series tile opens a series screen (TMDB hero, seasons, episode names); torrents can be renamed and given another poster; «Справка» is on the TV.

**Architecture:** the phone's series code (`seriesGroups`, `seriesStatus`, `tmdbShow`, `seriesMatch`, `episodeNames`) moves to `src/lib/` and gets its TMDB client from a platform-neutral provider (`src/catalog/activeCatalog.ts`); the phone registers `phoneCatalog`, the TV registers a new `tvCatalog` (native HTTP on Android TV, `fetch` on webOS). TV screens are Preact + norigin spatial navigation, like the existing ones.

**Tech Stack:** Preact, @preact/signals, @noriginmedia/norigin-spatial-navigation, vitest + jsdom, TypeScript; TV bundle targets Chromium 53 (webOS 4).

**Spec:** `docs/superpowers/specs/2026-10-06-v0.18-tv-design.md` (section «beta.1»). Mockups: https://claude.ai/artifact/VCR6KkWh79rmRvUMrHW2jL (artboards 1 «Медиатека», 2 «Экран сериала»).

## Global Constraints

- TV code in `src/` must run on Chromium 53: no `?.`, no `??`, no `Array.prototype.flat/flatMap`, no `Object.fromEntries`, no `String.prototype.replaceAll`, no CSS `gap` on flex containers for the TV (use margins; `gap` is fine on grid), no `inset`, no `aspect-ratio`.
- All user-visible copy through `t()` / `tp()` with keys in BOTH `src/i18n/ru.ts` and `src/i18n/en.ts` (ru plural `{one,few,many}`, en `{one,other}`). No Cyrillic in `.ts/.tsx` outside the dictionaries (test `tests/i18n/noRussianInCode.test.ts`); regex literals and comments are allowed.
- Reuse before adding: existing keys `series.*`, `torrent.rename.*`, `faq.*`, `player.resume*` are used where their wording fits.
- The phone must keep working exactly as before: every existing test in `mobile/tests/` stays green.
- Commands: tests `npx vitest run`; types `npx tsc --noEmit -p .` and `npx tsc --noEmit -p mobile`; TV build `npm run build`; boot check `npm run check:boot` (after `npm run build`).
- Commit messages in English, conventional style (`feat(tv): …`, `refactor: …`), no co-author or AI lines.
- Never print or commit secrets (signing key, TMDB fallback key is injected at build time — `src/catalog/fallbackKey.ts` stays `''`).
