# v0.4 «Облик OMP» — дизайн

Дата: 2026-10-02 · Основа: v0.3.0 (`main` @ ca9ee1f) · Решения пользователя: название **OMP — Open Movie Player**, логотип — вариант **D «Кадр плёнки»** (янтарный #F5B700), набор SVG-иконок одобрен (холст вариантов: https://claude.ai/artifact/A923n76zb2oAkmZgeQtm8C).

## Состав

1. **Переименование.** Название в лаунчере ТВ `OMP`; заголовок страницы `OMP`; экран подключения — логотип + «OMP» и подпись «Open Movie Player»; «О приложении» — «OMP — Open Movie Player X.Y.Z»; `package.json` name `omp`. ID приложения на ТВ не меняется (`com.spacesarmat.torrplayer`) — иначе потеряются данные.
2. **Логотип D.** Исходник `assets/logo.svg` (кадр плёнки с перфорацией, янтарный #F5B700, Play #E8EAF0, плитка #181B22). Иконки ТВ `webos/icon.png` 80×80 и `webos/largeIcon.png` 130×130 рендерятся из `assets/icon.svg` скриптом `npm run icons` (`@resvg/resvg-js`), PNG хранятся в репозитории. В приложении — компонент `Logo` (встроенный SVG).
3. **Фирменный цвет.** Акцент интерфейса меняется с оранжевого на янтарный #F5B700; текст на янтарных заливках (кнопка/вкладка/пункт диалога в фокусе) — тёмный #0F1115 (контраст ≈ 11:1).
4. **SVG-иконки вместо символов.** Модуль `ui/icons.tsx`: `Icon` (play, pause, prev, next, back10, fwd10, tracks, stats, history, search, plus, settings, grid, list, check, star, chevronLeft, chevronRight) и `KeyDot` (red/green/yellow/blue). Заменяются: кнопки и подсказки плеера, подсказки библиотеки и торрента (цветные кнопки — `KeyDot`), «✓» просмотренного, «＋ Добавить», «▶ Воспроизвести всё», «★ избранное», «⬆/⬇» в поиске (словами «сиды / пиры»), «‹ ›» в переключателях настроек. `Button` получает необязательный `icon`.
5. **Плеер: клики указателем (Magic Remote / тачпад ThinQ).**
   - Одиночный клик по изображению — пауза/воспроизведение (срабатывает через 300 мс, если не последовал второй клик); в центре экрана кратко показывается значок паузы/воспроизведения.
   - Двойной клик в левой трети — назад, в правой — вперёд; по центру — ничего. Шаг: база (по умолчанию 5 с), затем 2×база (не больше 30), затем 30 с и далее по 30 с; серия сбрасывается через 2 с без двойных кликов или при смене направления. На стороне клика кратко показывается «−5 с» / «+10 с».
   - Клики по панели управления, плашкам и экрану ошибки не считаются кликами по изображению.
   - Настройка «Шаг двойного клика»: 5 / 10 / 15 с.
6. **GitHub.** README переписан под OMP: логотип, возможности, управление (пульт и указатель), пошаговая установка на ТВ (включая `npx.cmd` в PowerShell и passphrase), обновление, разработка. Описание репозитория и темы обновлены. Версия 0.4.0.

## Тестирование
Vitest: логика кликов/двойных кликов и серии шагов (фейковые таймеры), санитайзер новой настройки, рендер иконок не требуется. Ручная проверка в браузере (клики мышью). CI.
