# v0.3 «Удобство просмотра» — дизайн

Дата: 2026-10-02 · Основа: v0.2.0 (`main` @ 6c23be4) · Состав этапа согласован в дорожной карте.

## Возможности

1. **«Продолжить просмотр» с сервера.** Ряд в библиотеке учитывает не только позиции этого ТВ, но и тайм-коды из `/viewed` (если на сервере включено «Сохранять тайм-коды»). Локальные записи — первыми (по свежести), затем серверные, по одной на торрент. Для серверной записи длительность неизвестна: карточка показывает только позицию, полоска прогресса скрыта.
2. **Уведомление о новых торрентах.** После автообновления библиотеки новые торренты (которых не было в предыдущем списке/кэше) показываются тостом «Добавлено: …» (до 3 названий, иначе «Добавлено торрентов: N»). Первая загрузка после смены сервера/пустого кэша уведомлений не даёт.
3. **Запоминание дорожек для торрента.** Ручной выбор аудио или субтитров в плеере сохраняется для этого торрента (`tsp.trackPrefs`, ключ — hash) и применяется ко всем его файлам: аудио — по точной подписи, затем по языку; субтитры — «выкл» или по языку (встроенные, затем внешние). Без сохранённого выбора — прежние языковые настройки.
4. **Размер и сдвиг субтитров в плеере.** Меню «Дорожки» получает пункты «Размер субтитров» (меняет общую настройку) и «Сдвиг субтитров» (−5…+5 с, шаг 0,5; только для внешних субтитров, которые рисует приложение; сбрасывается при смене файла). Положительный сдвиг — субтитры позже.
5. **Пропуск заставки.** Если в файле есть главы (ffprobe `chapters`) и текущая глава называется как заставка (intro, opening, OP, заставка, опенинг, вступление), показывается плашка «Пропустить заставку — OK»; OK перематывает в конец главы. Без глав функция не показывается (большинство раздач глав не имеют — это ожидаемо).
6. Версия 0.3.0, README.

## Решения
- Чистая логика — в модулях с тестами: `store/progress.ts` (`continueWatching`), `store/library.ts` (`addedTorrents`), `player/trackPrefs.ts` (выбор с учётом предпочтений), `store/trackPrefs.ts` (хранение + санитайзер), `player/subtitleOffset.ts` (варианты сдвига), `player/chapters.ts` (`introChapter`).
- `FfprobeResult` получает необязательное поле `chapters`.
- Плеер: при активной плашке пропуска заставки OK перематывает (приоритет ниже плашки следующей серии); Назад скрывает плашку для этой главы.

## Тестирование
Vitest для всех чистых функций; ручная проверка плеера в браузере против реального TorrServer; CI на PR.

## Вне рамок
Автоматическое определение заставки без глав; сдвиг встроенных субтитров (их рисует ТВ).
