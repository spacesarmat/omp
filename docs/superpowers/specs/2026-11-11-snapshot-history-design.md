# Полноценная история снимков

## Цель

Дать пользователю создавать именованные снимки темы и логики, сравнивать их с текущим preview, восстанавливать и удалять.

## Реализация

- `SnapshotPanel` в правом инспекторе: имя, создание, список, сравнение, восстановление, удаление.
- Кнопка Snapshot в header открывает и закрывает панель.
- Пустое имя показывает ошибку без исключения наружу. Лимит 10 показывает ошибку.
- Сравнение использует тему снимка вместо исходной default темы. Выход из сравнения возвращает текущую.
- Восстановление использует существующий `DraftController.restore` и остаётся совместимым с undo/redo.
- `deleteSnapshot(id): boolean` удаляет только выбранный снимок и создаёт один undo step.
- Ошибки не блокируют остальные снимки.

## Проверка

- Controller: удаление и undo.
- Panel: именованное создание, compare callback, restore, delete, пустое имя и лимит.
- App: сравнение переключает preview theme и возвращает текущую.
- Полный набор, TypeScript, сборка и браузерная проверка.
