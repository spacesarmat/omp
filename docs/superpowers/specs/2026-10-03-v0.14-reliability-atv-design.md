## 1. Android в CI

- Workflow CI (`.github/workflows/ci.yml`) получает job Android: JDK 21, Android SDK (platform-tools), `npm run build:mobile`, синхронизация, `gradlew assembleDebug` и `testDebugUnitTest` (через `scripts/gradle.mjs` или прямой gradle). Кэш gradle. Release workflow не меняется.

## 2. Журнал ошибок (телефон; Android TV — тоже пишет, экран — на телефоне и в настройках ТВ кратко)

- Модуль журнала (общий `src/lib/log.ts`): уровни ИНФО/ВНИМАНИЕ/ОШИБКА, область (приложение, сервер, поиск, мониторинг, ТВ, установка), время, короткий текст; кольцевой буфер 500 записей в `tsp.log`. Очистка личного: URL → только схема и «сервер»/имя сайта-источника; без query-строк, логинов, названий раздач, хешей. Перехват `window.onerror` / unhandledrejection, ошибки запросов (тип и код), итоги мониторинга, ошибки нативных вызовов.
- Экран «Настройки» → «Журнал ошибок» по макету: фильтры «Все / Ошибки / Мониторинг», «Сообщить об ошибке на GitHub» (открывает `https://github.com/spacesarmat/omp/issues/new?title=…&body=…` с версией OMP, Android, моделью, WebView, кратким описанием; полный журнал копируется в буфер обмена и в тело не кладётся целиком, если длинный), «Поделиться журналом» (файл `omp-журнал-<дата>.txt` через системное «Поделиться»), «Очистить».

## 3. Android TV наравне с телефоном

- **«Источники поиска» на ТВ** (Android TV UI, `src/`): список как на телефоне — TorrServer (rutor, Torznab) и встроенные сайты, переключатели, состояние; rutracker «Войти»/«Выйти». Слева — как передать с телефона и время последней передачи.
- **Вход на rutracker на ТВ:** окно с полями «Логин»/«Пароль» (ввод пультом или «Клавиатура» с телефона), хранение — зашифрованное хранилище Android TV.
- **«Передать на телевизор»** на телефоне в «Источниках поиска»: при подключённом Android TV — отправить включённые источники и (галочка) вход на rutracker по каналу пары (ControlServer с токеном); на ТВ — применить и сохранить секреты в зашифрованное хранилище; ответ «Передано». LG — не поддерживается (там нет встроенных источников).
- **Заставка и титры вручную на ТВ:** из блока «Пропуск» карточки на ТВ (LG и Android TV) — окно «Заставка с / до», «Титры: последние», стрелки ◀ ▶ шаг 5 с (удержание — 30 с), «Сбросить», «Сохранить» (тот же журнал `omp.s`).

## 4. Резервная копия (телефон)

- «Настройки» → «Резервная копия» по макету: что сохраняется (серверы и имена, пароль доступа к TorrServer если задан, телевизоры и пары, подписки и настройки мониторинга, источники вкл./выкл., настройки приложения и тачпада, вид каталога) и что нет (пароли трекеров и cookie; история и «Пропуск» — на TorrServer).
- «Сохранить копию…» → файл `omp-копия-<дата>.json` (версия формата, версия OMP, дата) через «Поделиться»; «Восстановить из файла…» → выбор файла, проверка формата, показ содержимого, подтверждение, замена; проверка каждого ключа теми же sanitizer'ами. Предупреждение про пароль TorrServer в файле.

## 5. Помощник установки (телефон)

- Вход: «Настройки» → «Установить OMP на телевизор» и из экрана «Телевизор», если ТВ найден без OMP.
- **Поиск устройств:** LG — SSDP (уже есть); после согласия на ТВ (пара SSAP) — модель, версия webOS, установлены ли OMP / Homebrew Channel (`listApps`). Android TV/Google TV — mDNS `_googlecast._tcp` (имя, модель) и/или ввод IP вручную.
- **Шаги под модель:** LG webOS < 4 — «не поддерживается»; есть OMP — версия и «Обновить на ТВ»; есть Homebrew Channel — «Установить OMP через Homebrew Channel» (открыть HBC на ТВ с репозиторием) или сразу установить; нет — путь Developer Mode с проверкой каждого шага (аккаунт LG, приложение Developer Mode, Dev Mode Status, Key Server) и ссылкой на rooting-проверку. Android TV — шаги «Для разработчиков» → «Отладка по сети» (или «Беспроводная отладка» на Android 11+).
- **Установка с телефона:**
  - **LG Developer Mode:** телефон забирает ключ с ТВ (Key Server, порт 9991) по коду (passphrase) из приложения Developer Mode, подключается по SSH (порт 9922, пользователь prisoner), загружает ipk OMP (из последнего релиза GitHub, проверка sha256 из ленты обновлений) и Homebrew Channel (по желанию) и ставит через сервис установки webOS; показывает прогресс и итог.
  - **Android TV:** adb по сети (порт 5555) или сопряжение «Беспроводной отладки» Android 11+ по коду; загрузка APK последнего релиза (проверка подписи/sha256), установка, итог. ТВ показывает запрос «Разрешить отладку» — подсказка.
  - Ошибки по-русски с подсказкой следующего шага; ничего не отправляется никуда, кроме ТВ и GitHub (скачивание релиза).
- Библиотеки — проверенные (SSH — например JSch/sshj; adb — например dadb), с учётом лицензий; без хранения ключей/паролей дольше сеанса установки.

## 6. Мелочи из ревью

- Подписи для экранного диктора у списка глав (`aria-current`), «Глава N» без повторов у глав без названий, ограничение длины списка глав в состоянии для телефона.
- Строка «Заставка и титры» в карточке: «по главам файла» плюс ручная отметка, если одна из двух задана вручную.
- LG-бандл не включает парсеры сайтов (проверить импорт и вынести за `platformKind() === 'androidtv'` через динамический импорт или раздельные точки входа, если это уменьшает бандл).

## Ограничения

- ТВ-код (`src/`) — правила Chromium 53, без `@capacitor`.
- Пароли трекеров, ключи SSH, коды сопряжения — только в памяти на время операции или в зашифрованном хранилище; никогда в журнал, localStorage, резервную копию, тесты.
- Тексты только на русском. Без строк соавторства.
