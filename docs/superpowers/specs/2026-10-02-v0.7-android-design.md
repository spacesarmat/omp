# v0.7 «OMP для Android» — дизайн

## Решения пользователя

- **Стек:** Capacitor 8 + Preact + TypeScript, общий код с приложением для ТВ. Нативный код (Kotlin) — только для того, чего нет в WebView.
- **Видео на телефоне:** только во внешнем плеере (VLC, MX Player и т. п.) через системный выбор приложения.
- **Скриншоты для GitHub:** из макетов, с вымышленными названиями (как в v0.5).
- Устройства Apple не поддерживаем: iPhone отложен.

## Что делает приложение

1. **Подключение к TorrServer.** Адрес, логин и пароль, сохранённые серверы. Кнопка «Сканировать QR с телевизора» переносит сервер, логин и пароль с ТВ.
2. **Каталог и История.** Вкладки как на ТВ, постеры в две колонки, значки качества, поиск, сортировка. В «Истории» кнопка «Продолжить на ТВ».
3. **Раздача.** Главная кнопка «Продолжить на ТВ · SxxEyy с mm:ss» (или «Смотреть на ТВ»), кнопка «Смотреть на телефоне», список серий с прогрессом. Нажатие на серию открывает панель «Где смотреть»: на ТВ, на телефоне (внешний плеер), скопировать ссылку.
4. **Добавить.** Magnet-ссылка или хеш, поиск через источники TorrServer (встроенный и Torznab). У результата кнопки «Добавить» и «Добавить и смотреть на ТВ». Ссылки `magnet:` из других приложений (браузер, «Поделиться») открываются в OMP и попадают на этот экран.
5. **Телевизор.** Поиск телевизоров LG в сети и подключение с подтверждением на ТВ («Разрешить»). Телевизор запоминается. Ввод IP вручную.
6. **Пульт.** Крестовина и OK, Назад, Домой, Меню, перемотка ±10 с, предыдущая/следующая серия, пауза, громкость, клавиатура (ввод текста в поле на ТВ), тачпад (курсор Magic Remote), выключение ТВ.
7. **Обновление.** Проверка новой версии при запуске (как на ТВ), панель «Доступна версия», скачивание с прогрессом, установка через системный установщик Android.

Значок подключённого ТВ в шапке каталога. Нажатие ведёт на экран «Телевизор».

## Как телефон управляет телевизором

Используется протокол второго экрана webOS (SSAP), тот же, что у LG ThinQ:

- **Поиск.** SSDP M-SEARCH на `239.255.255.250:1900` с `ST: urn:lge-com:service:webos-second-screen:1`. Ответы дают IP и имя ТВ (из описания устройства по `LOCATION`).
- **Соединение.** WebSocket `ws://<ip>:3000`. Если не вышло, `wss://<ip>:3001`: новые webOS принимают только его, сертификат самоподписанный, доверяем ему только для этого IP. Нужен нативный код: WebView такой сертификат отвергает.
- **Сопряжение.** Сообщение `register` с манифестом разрешений. Первый раз ТВ показывает запрос, пользователь нажимает «Разрешить», ТВ возвращает `client-key`. Ключ сохраняется вместе с ТВ, дальше подключение без запроса. Формат манифеста берётся по образцу открытых библиотек (lgtv2, aiowebostv), перечень разрешений минимальный под функции ниже.
- **Команды:**
  - запуск OMP с параметрами — `ssap://system.launcher/launch` `{ id: 'com.spacesarmat.torrplayer', params }`;
  - громкость — `ssap://audio/volumeUp`, `ssap://audio/volumeDown`;
  - выключение — `ssap://system/turnOff`;
  - ввод текста — `ssap://com.webos.service.ime/insertText`, `deleteCharacters`, `sendEnterKey`;
  - кнопки и курсор — `ssap://com.webos.service.networkinput/getPointerInputSocket` возвращает адрес второго сокета; в него идут `type:button\nname:UP\n\n` (UP, DOWN, LEFT, RIGHT, ENTER, BACK, HOME, MENU, PLAY, PAUSE…), `type:move\ndx:…\ndy:…\ndown:0\n\n`, `type:click\n\n`.
- **Если OMP на ТВ не установлен** (ошибка запуска): сообщение «На телевизоре нет OMP» и ссылка на README с установкой.

## Изменения в приложении для ТВ (v0.7 общая версия)

1. **Новый параметр запуска** `{ torrent: hash, file: <index>, t?: <секунды> }`. Открывает плеер на файле `file` раздачи с позиции `t`. Без `t` — как обычный запуск файла (с вопросом «Продолжить просмотр?», если есть сохранённая позиция). Вместе с `server` работает как в v0.6. Неверный `file` или `t` — тост «Некорректные параметры запуска».
2. **Экран «Подключить телефон».** Настройки → «Подключить телефон». Показывает QR-код с данными активного сервера и подпись «Откройте OMP на телефоне → Сканировать QR с телевизора». Формат QR: `omp://pair?v=1&url=<url>&name=<name>&user=<user>&password=<password>`, значения через `encodeURIComponent`, пустые поля опускаются. Предупреждение мелким текстом: «QR содержит пароль сервера — не показывайте его посторонним».

Версия общая для ТВ и телефона: 0.7.0.

## Устройство кода

```
src/                ТВ (как сейчас)
src/api, src/lib    общие модули — без изменений интерфейсов, импортируются мобильным приложением
mobile/             мобильный клиент
  index.html
  src/main.tsx, app.tsx
  src/screens/      Connect, Library, Torrent, Add, Remote, Tv, Settings, Update
  src/ui/           NavBar, Sheet, Poster (мобильные версии), стили mobile.css
  src/tv/           ssap.ts (чистая логика сообщений), tvStore.ts (сохранённые ТВ), tvClient.ts (поверх плагина)
  src/platform/     lgtv.ts (обёртка нативного плагина), intents.ts (внешний плеер, magnet), apkUpdate.ts
android/            проект Capacitor (Gradle), нативный плагин OmpNative (Kotlin)
capacitor.config.ts
vite.mobile.config.ts
```

**Сборка мобильной части:**
- отдельный конфиг Vite; современный WebView (Chrome 90+), без legacy-плагина;
- выход в `dist-mobile/`, который Capacitor копирует в `android/`.

**Общие модули:** берутся из `src/api` и `src/lib` как есть, через путь `../src/...`. Хранилища `src/store/servers`, `settings`, `library`, `progress`, `updates` тоже работают на телефоне (localStorage `tsp.*`). Хранилище ТВ — `tsp.tvs`.

**Нативный плагин `OmpNative`** (Kotlin, `android/app/src/main/java/.../OmpNativePlugin.kt`). Методы:

| Метод | Что делает |
|---|---|
| `discoverTvs({ timeoutMs })` | `{ tvs: [{ ip, name, model }] }` через SSDP |
| `tvConnect({ ip, clientKey? })` | соединение и `register`; события `tvPairingPrompt`, `tvConnected { clientKey }`, `tvDisconnected` |
| `tvRequest({ uri, payload })` | ответ ТВ |
| `tvButton({ name })`, `tvMove({ dx, dy })`, `tvClick()` | кнопки и курсор через pointer-сокет (открывается при первой команде) |
| `tvDisconnect()` | разорвать соединение |
| `openExternal({ url, mime })` | Intent `ACTION_VIEW` с выбором приложения |
| `downloadAndInstallApk({ url, sha256 })` | загрузка, события `apkProgress { percent }`, проверка SHA-256, системный установщик через FileProvider |
| `getPendingMagnet()` | magnet из Intent (`VIEW magnet:` или `SEND text/plain` со ссылкой magnet); событие `magnetReceived { link }` |

SSDP, WebSocket и загрузка — в фоновых потоках (OkHttp). Сетевой обмен с ТВ разрешён по cleartext только для локальных адресов (`network_security_config`).

**Сторонние плагины Capacitor:**
- `@capacitor/clipboard` — копирование ссылки;
- `@capacitor-mlkit/barcode-scanning` — сканер QR через Google Code Scanner, без разрешения на камеру;
- `@capacitor/app` — события возврата и Back.

**Идентификатор:** `com.spacesarmat.omp`. Название «OMP», иконка из логотипа D (адаптивная, из `assets/icon.svg`).

## Обновление Android-приложения

- **Релиз.** Workflow собирает подписанный релизный APK (`omp-<version>.apk`) и прикладывает его к релизу на GitHub. В `gh-pages` публикуется `update-android.json` того же формата, что `update.json` (version, apkUrl, sha256, size, notes, releaseUrl).
- **Приложение.** При запуске проверяет обновления (раз в 6 ч, отключается в Настройках). Логика — общая `store/updates.ts` с другим URL и полем `apkUrl` вместо `ipkUrl`: проверка и разбор обобщаются без изменения поведения ТВ. Панель «Доступна версия» → «Установить»: скачивание с прогрессом → системный установщик. При первой установке Android сам попросит разрешить установку из этого приложения.
- **Подпись.** Ключ подписи создаётся один раз и хранится в секретах GitHub (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`). Без него обновления «поверх» невозможны. Копию ключа пользователь хранит у себя, в репозиторий он не попадает. Создание ключа и запись секретов — отдельный шаг с подтверждением пользователя.
