# OMP 0.19.0-beta.1 — фильмография и 2160 Player

Дата: 2026-10-07. Платформы: телефон (Android), LG webOS (Chromium 53), Android TV — если не сказано иное.

Две независимые части по отзывам пользователей и запросу владельца.

## Часть A. Фильмография актёров и режиссёров

### Данные (`src/catalog/`, общие для всех платформ)

- `Person` получает `id` (TMDB person id) и `job` (`cast` | `director` | `creator`).
- Карточка фильма/сериала: актёры — до 15 (сейчас 8), плюс режиссёр(ы) фильма (`credits.crew`, `job = Director`) или
  создатели сериала (`created_by`). Режиссёры/создатели идут первыми с подписью «Режиссёр» / «Создатель».
- Новый запрос `person(id)`: `person/{id}?append_to_response=combined_credits` на языке интерфейса.
  Берутся имя, фото, годы жизни (`birthday`/`deathday`). **Биография не показывается.**
- Фильмография: для актёра — `combined_credits.cast`, для режиссёра/создателя — `combined_credits.crew` с
  `job ∈ {Director, Creator}` (у сериалов создатель приходит как `crew` с `job = Creator` или `department = Writing`;
  берём `Director` и `Creator`). Дубли (один тайтл несколько ролей) склеиваются, роли через запятую. Ток-шоу, новости,
  реалити и ток-шоу-появления скрыты, как в «Обзоре» (жанры 10763, 10764, 10767). Без постера — в конец.
- Кэш — как у остальных запросов TMDB.

### Экран «Человек» (в «Обзоре»)

- Шапка: фото, имя, годы жизни, профессия («Актёр», «Режиссёр»).
- Переключатели: «Все / В медиатеке» и сортировка «По популярности / По году».
- Сетка постеров в стиле «Обзора», под названием — роль (у режиссёра — «Режиссёр»).
- **Тайтлы, которые уже есть в «Моих»:** яркая рамка цветом акцента, пометка «В медиатеке», и в любой сортировке
  они идут первыми. Нажатие ведёт сразу в «Мои» — экран сериала или раздачи фильма.
- Остальные — обычная карточка «Обзора» («Найти раздачи», «Хочу посмотреть»).
- ТВ: жёлтая кнопка на плитке — «Хочу посмотреть», как в «Обзоре»; «Назад» возвращает фокус на человека, с которого
  пришли.
- «Только в медиатеке» без совпадений — строка «В медиатеке нет фильмов с …».

### Где появляются люди

- «Обзор», карточка: блок «В ролях» (и режиссёр/создатели) становится нажимаемым → экран «Человек».
- «Мои», экран сериала (телефон и ТВ): блок «В ролях» под сезонами.
- «Мои», экран раздачи фильма: блок «В ролях», если раздача сопоставлена с TMDB.

### Совпадение с медиатекой

Используется существующая логика пометки «В медиатеке» в «Обзоре» (сопоставление раздач с TMDB id). Для сериала —
любая раздача любого сезона.

## Часть B. 2160 Player через Intent API (только Android: телефон и Android TV)

### Выбор плеера

- Настройки плеера: строка «Плеер для видео: Встроенный / 2160 Player». По умолчанию — встроенный.
- «2160 Player» доступен, если установлен `tv.p2160.player` (или `tv.p2160.player.debug`); проверка через
  `PackageManager` с `<queries>` в манифесте. Не установлен — пункт неактивен, рядом подсказка со ссылкой
  `https://github.com/spacesarmat/2160player/releases/latest` (на ТВ — QR-код).
- Пометка у пункта: «QR поддержки и управление с телефона работают только во встроенном плеере».

### Запуск

Когда выбран 2160 Player, «Смотреть» (ТВ) и «Смотреть на телефоне» запускают его явно, без системного выбора:
`Intent(ACTION_VIEW)`, `setComponent(<пакет>, tv.p2160.core.Player2160Activity)`, тип `video/*`, запуск на результат.
Extras:

- `title` — «Сериал — S01E02» / название фильма;
- `position` (мс) — место остановки (≥ MIN_RESUME), либо `from_start=true` при «С начала»;
- `tv.p2160.extra.SEGMENTS` — заставка и титры из «Пропуска» (`intro:<s>-<e>;credits:<s>-`), если заданы;
- для сериала — `video_list` (Uri[] серий сезона по порядку) и `video_list.name`; `data` — стартовая серия;
- `return_result=true`.

### Результат

- `RESULT_OK`: `data` (Uri серии, на которой закрыли), `position`/`duration` (Int мс; запасные `extra_position`/
  `extra_duration` Long), `end_by` (`playback_completion` → досмотрено).
- По `data` находим серию в плейлисте; сохраняем место остановки / «просмотрено» как встроенный плеер
  (локально + TorrServer `/viewed`). Серии плейлиста до неё, которые были пройдены по «Следующая серия», отдельно не
  отмечаются (2160 Player их не сообщает).
- `RESULT_CANCELED` / нет данных — ничего не меняем.

### Код

Возвращается и дорабатывается удалённый в 0.18.0-beta.4 `player/ExternalPlayer.kt` (разбор результата уже
написан и покрыт тестами): явный компонент вместо chooser, плейлист, отрезки, сопоставление `data` с серией.
Плагин `OmpNative.openPlayer` принимает `{ package, url, title, positionMs, fromStart, segments, playlist? }`.

## Тесты и проверка

- TMDB: разбор `person` (без дат, без фото), склейка ролей, фильтр жанров, режиссёры/создатели.
- Экран «Человек»: переключатели, «В медиатеке» первыми, переходы (телефон и ТВ).
- 2160 Player: сборка Intent (Kotlin unit), разбор результата с плейлистом, настройка с установленным/неустановленным
  плеером.
- На устройствах: LG, Dune (с установленным 2160 Player), S21 — скриншоты чистых экранов.
