# v0.8 «Управление плеером с телефона» — дизайн

Дата: 2026-10-02 · Основа: v0.7.1 (`main`) · Ветка `feat/v0.8-player-control`
Макеты одобрены: https://claude.ai/artifact/Tnk5bMpnbpRgprAaysjqkP

## Зачем

Замечания пользователя после v0.7:
1. «Смотреть на ТВ» должно сразу включать серию: продолжить с места остановки или сначала, по выбору.
2. На телефоне нужен полноценный плеер-пульт: пауза, перемотка, серии, дорожки.

Samsung Tizen и Android TV переносятся на v0.9.

## Что видит пользователь (телефон)

1. **«Сейчас играет»** (новый экран, маршрут `nowPlaying`). Обложка, название серии, «Раздача · SxxEyy», телевизор. Полоса перемотки с ползунком: прошло / осталось; перетаскивание отправляет переход при отпускании. Кнопки: предыдущая серия, −10 с, пауза/воспроизведение, +10 с, следующая серия. «Звук и субтитры», громкость (как на пульте). Карточка «Дальше: SxxEyy · Название — Включить», если есть следующая серия. Вверху «Свернуть» (назад) и кнопка «Пульт».
2. **«Звук и субтитры»** — нижняя панель: список звуковых дорожек и субтитров, текущие отмечены. Список и выбор приходят с ТВ.
3. **Мини-плеер** — полоса над нижней панелью на всех экранах с вкладками, пока на ТВ играет OMP: обложка, «SxxEyy · Название», «На <ТВ> · 23:14 из 48:32», −10 с, пауза, тонкая полоса прогресса. Нажатие на текст открывает «Сейчас играет».
4. **«Откуда смотреть?»** — при запуске на ТВ файла с сохранённой позицией (главная кнопка раздачи, серия в списке, ▶ в «Истории»): «Продолжить с mm:ss» (с подписью «Осталось N минут», если известна длительность) и «Сначала», «Отмена». Без позиции файл запускается сразу. «Сначала» отправляет `t: 0`: ТВ начинает с начала без вопроса.
5. **«Обновите OMP на телевизоре»** — если на ТВ OMP старше 0.8: версия на ТВ, пояснение, подсказка «Настройки → Обновление → Проверить обновление». Кнопки «Всё равно запустить» (запуск как раньше) и «Как обновить» (README).
6. Если ТВ перестал присылать состояние дольше 5 с — мини-плеер и экран показывают «Телевизор не отвечает»; через 30 с мини-плеер скрывается.

Экран «Пульт» не меняется.

## Канал телефон ↔ ТВ

ТВ-приложение не может принимать входящие соединения, а телефон может. Поэтому:

- **Телефон поднимает маленький HTTP-сервер** (нативный плагин, порт выбирает система) на адресе, через который он видит телевизор. Путь содержит случайный токен (128 бит): `http://<ip>:<port>/omp/<token>`. Чужие пути — 404.
- **Подключение плеера («attach»).** Телефон передаёт этот адрес в параметре запуска `report`:
  - вместе с запуском файла: `{ server, torrent, file, t?, report }`;
  - отдельно, если OMP уже открыт на ТВ: `{ report }` — только когда приложение на переднем плане ТВ — OMP (`ssap://com.webos.applicationManager/getForegroundAppInfo`), чтобы не выдёргивать OMP поверх другого приложения. Телефон делает это при подключении к ТВ и при возвращении приложения на экран.
- **Обмен.** ТВ раз в 500 мс отправляет `POST <report>` с телом `text/plain` (JSON, без предварительного CORS-запроса). Ответ — JSON со списком команд, накопленных телефоном с прошлого запроса; телефон их отдаёт один раз. После выполнения команды ТВ отправляет состояние сразу, не дожидаясь интервала.
- **Отключение.** ТВ перестаёт слать после 20 с без успешного ответа или когда приходит новый `report` (заменяет старый). Телефон, получив `state: null`, скрывает мини-плеер.
- Сервер работает, пока жив процесс приложения; при уходе приложения в фон состояние продолжает приниматься.

### Сообщение ТВ → телефон

```json
{
  "v": 1,
  "app": "0.8.0",
  "state": {
    "hash": "<40 hex>", "file": 3,
    "title": "Тишина в эфире", "subtitle": "Starbound Frontier · S02E03", "poster": "https://…",
    "time": 1394.2, "duration": 2912.0, "paused": false, "buffering": false,
    "audio": { "list": ["Русский · AC3 5.1", "English · AAC 2.0"], "sel": 0 },
    "subs": { "list": [{ "label": "Выкл", "value": "off" }, { "label": "Русские", "value": "e0" }], "sel": "e0" },
    "next": { "title": "S02E04 · Граница" }
  }
}
```

`state: null` — OMP открыт, но плеер не играет.

### Команды телефон → ТВ

Ответ: `{ "cmds": [ { "id": 7, "type": "pause" }, … ] }`. Типы:

| type | поля | действие на ТВ |
|---|---|---|
| `play` / `pause` | — | воспроизвести / пауза |
| `seek` | `t` (с) | перейти к позиции |
| `skip` | `d` (с, ±) | сдвиг от текущей позиции |
| `next` / `prev` | — | следующая / предыдущая серия очереди |
| `audio` | `i` | звуковая дорожка по индексу из `audio.list` |
| `subs` | `value` | субтитры: значение из `subs.list` |

Неизвестные типы и неверные поля игнорируются. Команды выполняются только в плеере; вне плеера отбрасываются.

## Версия OMP на ТВ

Перед запуском файла телефон запрашивает `ssap://com.webos.applicationManager/listApps` (разрешение `READ_INSTALLED_APPS` уже есть) и берёт `version` у `com.spacesarmat.torrplayer`. Версия ниже 0.8.0 — диалог «Обновите OMP на телевизоре». Если версию узнать не удалось — запускаем как обычно. Результат кэшируется на сессию подключения.

## Изменения на ТВ

- `launchParams`: параметр `report` — строка `http://…` длиной до 200 символов; иначе «Некорректные параметры запуска». `{ report }` без других параметров допустим.
- Новый модуль связи с телефоном (`src/phone/link.ts`): хранит адрес, цикл отправки, разбор и проверка команд, отключение по ошибкам. HTTP — через XHR (Chromium 53, тайм-аут 3 с).
- Плеер публикует снимок состояния и регистрирует обработчик команд (через модуль связи), используя существующие `togglePause`, `seekTo`, `goNext`, `goPrev`, выбор дорожек и субтитров. Остальные экраны публикуют `state: null`.
- Короткая всплывающая подсказка на ТВ при первой команде с телефона: «Управление с телефона».

## Изменения на телефоне

- Нативный плагин: `startPlayerServer({ tvIp })` → `{ url }` (адрес выбирается по интерфейсу, через который виден ТВ), `stopPlayerServer()`, событие `playerState { body }`, метод `queuePlayerCommands({ cmds })` (или очередь целиком в JS: плагин держит очередь, JS добавляет команды). Простой HTTP/1.1 на `ServerSocket`, фоновые потоки, тело до 64 КБ, CORS-заголовок `Access-Control-Allow-Origin: *`.
- `mobile/src/tv/playerLink.ts`: состояние `nowPlaying` (signal), отметка последнего сообщения, отправка команд с оптимистичным обновлением (пауза, позиция), attach при подключении ТВ и при возврате приложения.
- Экраны и компоненты: `NowPlaying.tsx`, `ui/MiniPlayer.tsx`, `ui/TracksSheet.tsx`, `ui/ResumeSheet.tsx`, `ui/OldTvDialog.tsx`.
- `watchOnTvParams` передаёт `t: 0`; все точки запуска («Раздача», «Где смотреть», «История», «Добавить и смотреть на ТВ») проходят через общий запуск: проверка версии → выбор «Продолжить / Сначала» (если есть позиция) → запуск с `report`.

## Ограничения

- ТВ — Chromium 53 (правила прежние). Телефон — Android 8+, WebView Chrome 90+. Тексты только на русском.
- Никаких внешних серверов: обмен только внутри локальной сети.
- Без строк соавторства и подписей ИИ.
