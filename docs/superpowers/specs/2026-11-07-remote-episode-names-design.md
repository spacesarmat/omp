# Названия серий из TMDB в пульте

## Цель

В списке «Серии» пульта показывать код и название эпизода из TMDB, например `S06E03 · Название серии`, вместо технического имени файла. Имена и пути файлов, идентификаторы и порядок запуска не меняются.

## Подходы

1. Выбран: загружать через существующий `useTmdbEpisodes` все нужные сезоны один раз в родительском компоненте `Episodes` и передавать названия в `EpisodeRow`. На каждый сезон выполняется один запрос, ответы используют существующий кэш каталога.
2. Отклонен: запрашивать название отдельно в каждой строке через `episodeNameOf`. Это уменьшает diff, но при первом открытии списка может создать параллельные запросы одного сезона до заполнения кэша.

## Реализация

- `Episodes` получает номера сезонов из путей существующих файлов и вызывает `useTmdbEpisodes` для текущего торрента.
- `EpisodeRow` получает название TMDB по распознанным номерам сезона и эпизода.
- При наличии реального названия подпись формируется через существующий `episodeLine`: код и название.
- Пока TMDB загружается, недоступен, не нашёл сериал или содержит заглушку вроде «Эпизод 3», остаётся текущая подпись с именем файла.
- Свайп и запуск продолжают использовать исходный `TorrentFile` и его `id`.

## Проверки

- Сначала добавляется failing-тест списка пульта: после ответа TMDB видны коды и названия, а имя файла скрыто.
- Отдельно проверяется fallback для серии без названия и отсутствие изменений запуска файла.
- Затем выполняются полный `npm test`, `npm run build` и `npm run build:mobile`.

## Границы

- Не меняются файлы на устройстве, раздачи, карточка «Сейчас на ТВ», другие списки эпизодов и сервер.
- Не добавляются зависимости. Изменение проходит через отдельную ветку и PR, без вливания и релиза до разрешения Andy.
