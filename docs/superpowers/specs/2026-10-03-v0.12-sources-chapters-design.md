## Часть 1. Главы и пропуски

### Главы

- Источник глав — ffprobe TorrServer (`/ffp/<hash>/<index>`, поле `chapters`: `start_time`, `end_time`, `tags.title`). LG уже запрашивает его в плеере; Android TV запрашивает так же на стороне страницы и передаёт главы нативному плееру (при старте и при переходе к следующему файлу).
- Без ffprobe или без глав всё, что связано с главами, просто не показывается.
- **LG (плеер `src/screens/Player.tsx`):** отметки глав на полосе перемотки; кнопка/пункт меню «Главы» — список «время · название», текущая глава выделена, выбор перематывает к началу главы; кнопки пульта CH+ / CH− (Page Up / Page Down) — следующая / предыдущая глава (CH− в первых 3 с главы — к предыдущей, иначе к началу текущей).
- **Android TV (`PlayerActivity.kt`):** то же — отметки на полосе, «Главы» в меню плеера, CH+/CH−.
- **Телефон, «Сейчас играет»:** отметки на полосе, строка «Глава N из M · название» с кнопками «предыдущая / следующая глава», список глав. ТВ передаёт главы и номер текущей в состоянии плеера; телефон шлёт команду перехода к главе.

### Что считается заставкой и титрами

- Глава-заставка: название содержит intro, opening, op, заставка, опенинг, вступление (как сейчас), длина > 5 с.
- Глава-титры: credits, end credits, ending, ed, outro, титры, эндинг (слово целиком, регистр не важен), длина > 5 с.
- Без таких глав используются **ручные отметки** раздачи: заставка «с … до …» (секунды от начала), титры «последние N секунд». Главы файла важнее ручных отметок.

### Настройки пропуска (на раздачу)

- Хранятся в журнале на TorrServer: в объекте `omp` поля `data` раздачи появляется ключ `s`: `{ "i": true|false, "c": true|false, "mi": [start, end]?, "mc": seconds? }` — автопропуск заставки, автопропуск титров, ручная заставка, ручные титры. Версия журнала остаётся 1 (ключ дополнительный); запись истории сохраняет `s`, запись `s` сохраняет историю и все прочие ключи `data`; `data` не-JSON не трогаем.
- Действуют на все файлы раздачи. По умолчанию всё выключено.

### Поведение в плеере (LG и Android TV одинаково)

- **Заставка, автопропуск выключен:** кнопка «Пропустить заставку», пока идёт заставка (на Android TV — новая). OK — перемотка на конец, «Назад» — спрятать.
- **Заставка, автопропуск включён:** при входе в заставку сразу перемотка на её конец и сообщение «Заставка пропущена · Вернуть» на 5 с; OK — вернуться к началу заставки, в этом файле больше не пропускать.
- **Титры, автопропуск включён и есть следующая серия:** в начале титров сразу следующая серия, сообщение «Титры пропущены».
- **Титры известны, автопропуск выключен:** отсчёт «Следующая серия» начинается в начале титров (а не за 30 с до конца); без титров — как сейчас.
- **Фильм / последняя серия:** автопропуск титров ничего не делает.
- **Отметки из меню плеера:** «Отметить начало заставки», «Отметить конец заставки», «Отметить начало титров» — текущее время пишется в `s` раздачи (титры — как «последние N с» от длительности файла), сообщение «Отмечено: заставка с 0:45».

### Карточка раздачи

- **Телефон (`mobile/src/screens/Torrent.tsx`):** блок «Пропуск» — «Пропускать заставку», «Пропускать титры (сразу следующая серия)», строка «Заставка и титры» (подпись: «по главам файла» / «в файле нет глав · заставка 0:45–2:15» / «не заданы») → нижнее окно с полями «Заставка с / до», «Титры: последние (мин:сек)», «Сбросить», «Сохранить».
- **ТВ (LG и Android TV, `src/screens/Torrent.tsx`):** блок «Пропуск» с двумя переключателями и строкой состояния «Заставка и титры» (редактирование на ТВ — отметками из плеера).
- Сохранение — сразу, через журнал на TorrServer; ошибка — сообщение, переключатель возвращается.

## Часть 2. Источники

### Общий поиск

- Экран «Добавить» на телефоне ищет **во всех включённых источниках сразу**: TorrServer rutor (`/search`), TorrServer Torznab (`/torznab/search`) и встроенные сайты. Результаты появляются по мере ответа; строка «Найдено N · K из M источников ответили · ещё ищу в …».
- Повторы склеиваются: по infohash, если он известен, иначе по нормализованному названию + размеру (±1%). У склеенного результата — «ещё в nnmclub, BitRu».
- Фильтры: «Все источники · N» (выбор источников на этот поиск), качество «1080p+» / «2160p», сортировка «по сидам» (по умолчанию) / «по дате» / «по размеру».
- Ограничение: 15 с на источник; источник с ошибкой помечается в «Источниках» как «не отвечает».
- У результата: источник, размер, сиды, дата, категория (как в 0.11), «Добавить», «На ТВ». Если у результата нет magnet-ссылки — она берётся со страницы раздачи при нажатии.
- **Android TV:** экран поиска ТВ-интерфейса использует тот же общий поиск. **LG:** без изменений (TorrServer).

### Встроенные парсеры

- Модуль на сайт: `id`, `name`, `search(query, http) → SearchResult[]`, при необходимости `magnet(detailUrl, http)`; общий код: разбор HTML (DOMParser), размеры, даты, кодировка windows-1251.
- HTTP — через нативный плагин Android (`OmpNative.http`): без CORS, свой User-Agent, cookies на сайт, перекодировка по `charset`. В тестах — фикстуры HTML.
- Перед реализацией каждого сайта — проверка: поиск без входа отдаёт страницу, разбирается, есть magnet (на странице поиска или раздачи). Не прошедший проверку сайт не включается; в отчёте — какой и почему.
- **rutracker:** вход по логину и паролю (окно «Вход на rutracker»); логин, пароль и cookie сессии хранятся в зашифрованном хранилище Android (Keystore), отправляются только на rutracker. «Выйти» стирает их.

### Экран «Источники поиска» (Настройки → «Источники поиска»)

- «Через TorrServer»: rutor (поиск TorrServer), Jackett / Prowlarr (Torznab) — переключатели и состояние.
- «Встроенные · на телефоне»: каждый сайт — переключатель, состояние после последнего поиска («работает · 0,8 с», «не отвечает», «нужен вход»), «Войти» / «Выйти» для rutracker.
- Подсказка про Kinozal, seedoff, rustorka, labtor → Jackett/Prowlarr.
- Хранение: `tsp.sources` `{ [id]: { on: boolean } }` + состояние в памяти. По умолчанию включены все встроенные, кроме требующих входа.

## Ограничения

- ТВ-код (`src/`) — правила Chromium 53 (без подклассов Error, AbortController, CSS grid/flex `gap`/`inset`, regex без `u` и lookbehind), без `@capacitor` в `src/`.
- Телефон — Android 8+, WebView Chrome 90+. Тексты только на русском. localStorage — `tsp.*` через loadJson + проверку.
- Пароли трекеров — только в зашифрованном хранилище Android, никогда в localStorage, логах, журнале TorrServer.
- Без строк соавторства.
