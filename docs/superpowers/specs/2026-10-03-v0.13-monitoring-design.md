# v0.13 «Мониторинг» — дизайн

Дата: 2026-10-03 · Основа: v0.12.1 (`main`) · Ветка `feat/v0.13-monitoring`
Макеты одобрены: https://claude.ai/artifact/1Hh8km52vnDxfeLgVYCB4a

## Решения пользователя

- Фоновая проверка — **скрытая страница** с теми же парсерами, которую Android будит по расписанию (WorkManager); работает при закрытом приложении.
- По умолчанию раз в **3 часа**; выбор 1 / 3 / 6 / 12 часов; переключатель «Только через Wi-Fi» (включён).
- Новые серии сериала из каталога → **уведомление и «Заменить»**: новая раздача добавляется, история, «Пропуск» и категория переносятся, старая удаляется.
- Лента «Новое» — **свежее со встроенных сайтов**.
- Подписки и лента — **новая пятая вкладка внизу «Новое»**.
- Кнопки в уведомлении работают **в фоне** («Добавить», «Заменить»); «Смотреть на ТВ» открывает OMP; нажатие на уведомление — к результатам.
- Только телефон (Android TV и LG — без мониторинга).

## Вкладка «Новое»

- Пятая вкладка нижней панели между «Каталог» и «Добавить»; значок-колокольчик с числом непросмотренных находок (подписки + новые серии). Свайпы между вкладками учитывают пять вкладок.
- Переключатель «Лента · Подписки · N новых».
- **Лента:** свежие раздачи со встроенных сайтов, где у сайта есть страница «новое/топ» (rutor, nnmclub, torrent.by — какие получится; проверка как в v0.12), фильтры «Фильмы / Сериалы / Аниме» и «1080p+», строка «Свежее с … · обновлено в 14:20»; строки как в общем поиске («Добавить», «На ТВ», категория). Обновляется при открытии вкладки (не чаще раза в 10 минут) и при фоновой проверке.
- **Подписки:** список подписок (запрос, условия, «N новых»), «+ Новая подписка», «Проверить сейчас», «Проверено в … · следующая проверка около …». Нажатие на подписку — её находки (новые сверху) и «Изменить».
- **Новые серии сериалов из каталога:** карточки «Вышли серии 9–10 · у вас 1–8» с «Заменить…» и «Не следить».

## Подписки

- Подписка: запрос, качество (любое / 720p+ / 1080p+ / 2160p), минимум сидов, максимальный размер (ГБ, необязательно), источники (все включённые или выбранные), «Уведомлять» (вкл).
- Создаётся «+ Новая подписка» или из общего поиска — плашка «Сообщить, когда появятся новые раздачи по этому запросу · Подписаться» (с текущими фильтрами поиска).
- Проверка подписки: общий поиск по её источникам, фильтры подписки, сравнение с уже виденными раздачами подписки (по infohash, иначе по нормализованному названию + размеру). Первый прогон только запоминает найденное — без уведомлений.
- Хранение на телефоне: `tsp.subs` (подписки), `tsp.subsSeen` (виденные, до 300 на подписку), находки для экрана — `tsp.monitorFound` (последние 100).

## Новые серии

- Следим за раздачами каталога с категорией «Сериалы» (или распознанными как сериал по названию), у которых видна нумерация серий; выключается переключателем «Следить за новыми сериями» в карточке (хранится в журнале раздачи на TorrServer, ключ `omp.w: false` верхнего уровня журнала — не внутри `s`, чтобы клиенты v0.12 его не стирали) или «Не следить».
- Проверка: поиск по названию сериала (без качества/серий), среди результатов того же сезона ищем раздачу с бо́льшим номером последней серии, чем у текущей; предпочитаем то же качество и тот же источник/релиз-группу; диапазон серий берём из названия («Серии 1–10 из 10», «S02E01-10», «1-10 из 10»).
- Уведомление один раз на найденную новую последнюю серию.
- **«Заменить»** (окно на телефоне или кнопка в уведомлении): добавить новую раздачу (категория та же), перенести журнал (`omp.h` с сопоставлением файлов по метке серии SxxEyy / номеру; `omp.s`), название и обложку; затем удалить старую раздачу. При ошибке старая не удаляется. «Другая раздача» — выбор из других подходящих.

## Фон

- WorkManager: периодическая задача с выбранным интервалом и ограничением Wi-Fi; одноразовые задачи для «Проверить сейчас» и кнопок уведомлений.
- Задача поднимает скрытую WebView, которая загружает отдельную страницу мониторинга из бандла приложения (тот же origin, что у приложения, — общий localStorage с подписками и настройками), даёт ей мост: HTTP и секреты (как у OmpNative), уведомления, выбор сервера; страница выполняет проверку и закрывается. Таймаут задачи — 3 минуты.
- Уведомления: каналы «Подписки» и «Новые серии»; группировка; кнопки как в макете; результат действия — обновлённое уведомление «Добавлено на сервер» / «Заменено» / ошибка.
- Нужен доступный TorrServer: без него проверка подписок идёт (поиск по сайтам), а «Добавить/Заменить» сообщает «Сервер недоступен».
- Разрешение на уведомления (Android 13+) спрашивается при первом включении мониторинга или создании подписки.

## Настройки

- «Настройки» → «Мониторинг»: «Проверять в фоне» (вкл), «Как часто», «Только через Wi-Fi», «Следить за новыми сериями» (вкл), итог последней проверки (время, найдено, сколько источников ответило), подсказка про ограничения батареи.

## Ограничения

- ТВ-код (`src/`) — правила Chromium 53, без `@capacitor`; общий код мониторинга в `src/monitor/` (Chromium-53-safe), UI — в `mobile/`.
- Пароли и cookie — как в v0.12 (только зашифрованное хранилище).
- Тексты на русском. Без строк соавторства.
