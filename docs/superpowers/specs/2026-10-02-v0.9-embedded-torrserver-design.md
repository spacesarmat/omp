# v0.9 «TorrServer на телефоне» — дизайн

Дата: 2026-10-02 · Основа: v0.8.2 (`main`) · Ветка `feat/v0.9-embedded-torrserver`
Макеты одобрены: https://claude.ai/artifact/TFXnQB81jp5YieMopEwxGg

## Решения пользователя

- TorrServer (YouROK/TorrServer, GPL-3.0) встраивается в APK OMP.
- Только arm64: в APK кладётся `TorrServer-android-arm64` (~64 МБ). На 32-битных телефонах встроенного сервера нет, OMP работает как раньше.
- Обновление сервера: GitHub раз в день проверяет новые выпуски TorrServer и сам выпускает OMP x.y.z+1 с новым сервером.
- Samsung Tizen и Android TV — v0.10.

## Что видит пользователь

1. **Сервер не найден.** На экране подключения, когда нет сохранённых серверов и поиск в сети ничего не нашёл: строка «В сети не нашлось TorrServer» и выделенная карточка «TorrServer прямо на телефоне» — «OMP запустит встроенный сервер. Телевизор найдёт его сам, пока телефон в той же сети Wi‑Fi.» — кнопка «Запустить TorrServer на телефоне». Ниже прежние способы и «Искать в сети ещё раз». На телефоне без arm64 карточки нет.
2. **Запуск.** Экран «TorrServer на телефоне» со шагами: «Подготовка сервера <версия>», «Запуск в фоне», «Проверка связи», «Подключение OMP»; затем блок «Адрес для телевизора: <IP>:8090» с подсказкой «На ТВ: Вход → «Найти в сети». Сервер работает, пока телефон включён и в этой сети Wi‑Fi.» и кнопка «Открыть каталог». Сервер сохраняется как «Этот телефон» (`http://127.0.0.1:8090`) и становится активным. Ошибка шага — текст и «Повторить».
3. **Настройки → «TorrServer на телефоне»:** статус («Работает» / «Остановлен», версия, адрес в сети) и переключатель; «Запускать вместе с OMP»; «Кэш на телефоне: занято N из 1 ГБ» и «Очистить»; пометка «Новая версия сервера приходит вместе с обновлением OMP».
4. **Уведомление**, пока сервер работает: «TorrServer работает», «<IP>:8090 · N раздач · скорость», кнопки «Остановить» и «Открыть OMP».

## Как это устроено

- **Сборка.** Файл `torrserver.version` (например `MatriX.145.1`) в корне. Скрипт `scripts/fetch-torrserver.mjs` скачивает `TorrServer-android-arm64` этого выпуска с GitHub, сверяет SHA-256 из поля `digest` ассета (GitHub API) и кладёт в `android/app/src/main/jniLibs/arm64-v8a/libtorrserver.so` (в `.gitignore`). Вызывается перед `cap sync` локально и в `release.yml`. Gradle: `packaging.jniLibs.useLegacyPackaging = true`, чтобы файл распаковывался в `nativeLibraryDir` и его можно было запустить (Android 10+ запрещает запуск скачанных программ из папок приложения).
- **Служба.** `TorrServerService` — служба переднего плана (тип `specialUse`, разрешения `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS`, `WAKE_LOCK`). Запускает `<nativeLibraryDir>/libtorrserver.so --port 8090 --path <filesDir>/torrserver --logpath <filesDir>/torrserver/server.log`, держит `WifiLock` и частичный `WakeLock`, пока работает. Если процесс завершился сам — один перезапуск через 3 с, затем статус «Остановлен» с ошибкой. Уведомление раз в 5 с обновляет число раздач и скорость (`/torrents` с телефона).
- **Плагин.** `localServerInfo()` → `{ supported, running, version?, ip? }`, `startLocalServer()`, `stopLocalServer()`, `localServerCache()` → `{ usedBytes }`, `clearLocalServerCache()`, `localIpv4()`; событие `localServerState`. При первом запуске OMP через API TorrServer включает дисковый кэш в `<cacheDir>/torrserver` с пределом 1 ГБ.
- **Телефон.** Хранилище `localServer` (статус, автозапуск — настройка `tsp.localServer`). Автозапуск при открытии OMP, если включён. «Этот телефон» — обычная запись в списке серверов.
- **Запуск на ТВ.** Если активный сервер — `127.0.0.1`/`localhost`, в параметре `server` телевизору передаётся `http://<IP телефона>:8090`; так же для «Скопировать ссылку на поток». Нет IP (не Wi‑Fi) — сообщение «Телефон не в сети Wi‑Fi — телевизор не увидит сервер».
- **Телевизор** находит сервер на телефоне обычным «Найти в сети» (порт 8090).

## Автообновление сервера

- Workflow `torrserver-update.yml`: по расписанию раз в сутки и вручную. Берёт последний выпуск YouROK/TorrServer; если тег отличается от `torrserver.version` и в нём есть `TorrServer-android-arm64` с `digest`:
  - обновляет `torrserver.version`, поднимает патч-версию OMP (`package.json`, `package-lock.json`, `webos/appinfo.json`), добавляет в CHANGELOG `## x.y.z` «Встроенный TorrServer обновлён до <тег>»;
  - коммитит в `main`, ставит тег `vx.y.z` и вызывает сборку выпуска (`release.yml` как `workflow_call`, потому что тег, поставленный встроенным токеном, сам выпуск не запускает).
- Телефоны получают это как обычное обновление OMP.

## Ограничения

- Мобильная часть — Android 8+; встроенный сервер — только arm64.
- Сервер в сети без пароля, как обычный TorrServer по умолчанию. Предупреждение в Настройках: «Сервер доступен всем устройствам в этой сети Wi‑Fi».
- Лицензия: в README и «О программе» — TorrServer © YouROK, GPL-3.0, ссылка на исходники.
- Тексты только на русском; без строк соавторства.

## Тестирование

- Vitest: выбор ассета и разбор `digest` в скрипте; хранилище `localServer`; экран подключения (карточка есть/нет); экран запуска (шаги, ошибка); Настройки; подстановка IP телефона в параметры запуска и ссылку.
- Сборка `android:debug` с сервером; размер APK ~80 МБ.
- Вручную (пользователь): запуск сервера, уведомление, ТВ находит сервер, просмотр, остановка.

## Вне рамок

- 32-битные телефоны (armv7) со встроенным сервером.
- Пароль на встроенный сервер.
- Tizen и Android TV (v0.10).
