# webOS TorrServer Player — дизайн

Дата: 2026-10-02
Статус: на согласовании

## Цель

Медиапроигрыватель для LG webOS, который подключается к TorrServer (MatriX.145+) в локальной сети,
показывает торренты сервера, воспроизводит файлы и плейлисты с использованием аппаратного декодера ТВ
и управляется пультом LG, Magic Remote и приложением LG ThinQ на Android.

## Ограничения

- Целевые устройства: webOS 4.0+ (Chromium 53 и новее). Код транспилируется под Chrome 53,
  полифиллы через core-js по использованию.
- Разрешение интерфейса: 1920×1080 (масштабируется на 4K-панелях системой).
- Сеть: только HTTP в локальной сети, без внешних сервисов, кроме постеров, которые отдаёт TorrServer.
- Репозиторий: локально `C:\Users\ANDYBUM\webostorrserver` + GitHub `spacesarmat/webos-torrserver-player` (public).

## Стек

- Preact + TypeScript, сборка Vite; `@vitejs/plugin-legacy` с таргетом `chrome 53`.
- Пространственная навигация: `@noriginmedia/norigin-spatial-navigation`.
- Тесты: Vitest (+ jsdom для компонентов при необходимости).
- Упаковка/установка: `@webos-tools/cli` (`ares-package`, `ares-install`, `ares-launch`) как devDependency.

## Структура

```
src/
  api/        torrserver.ts — типизированный клиент; discovery.ts — поиск серверов в подсети
  store/      servers.ts, settings.ts, progress.ts — состояние + localStorage
  lib/        m3u.ts, episodes.ts (S01E02), subtitles.ts (SRT/VTT/ASS→cues), format.ts, keys.ts
  player/     Player.tsx, tracks.ts (audio/text tracks), webosMedia.ts (Luna-обёртка), Overlay*.tsx
  screens/    Connect, Library, Torrent, Player, Add, Playlist, Settings
  components/ Focusable-карточки, списки, диалоги, клавиатурные поля, тосты
  app.tsx     роутер экранов (стек с обработкой Back)
webos/        appinfo.json, иконки
```

Каждый модуль `lib/` и `api/` — чистые функции/классы без зависимостей от UI, покрываются юнит-тестами.

## API TorrServer (используемое)

| Задача | Запрос |
|---|---|
| Проверка сервера, версия | `GET /echo` |
| Список / детали / добавление / удаление | `POST /torrents` `{action: list|get|add|rem|drop}` |
| URL воспроизведения | `GET /stream?link=<hash>&index=<id>&play` (или `/play/{hash}/{id}`) |
| Предзагрузка | `GET /stream?link=<hash>&index=<id>&preload` |
| Дорожки/кодеки файла | `GET /ffp/{hash}/{id}` (если `/ffp/status` = available) |
| Статистика потока | `POST /cache {action:get, hash}` |
| Прогресс/просмотрено | `POST /viewed {action: set|list|rem, hash, file_index, timecode}` |
| Поиск | `GET /search?query=` (rutor), `GET /torznab/search?query=` |
| Плейлисты | `GET /playlist?hash=&fromlast`, `GET /playlistall/all.m3u` |
| Настройки сервера | `POST /settings {action: get|set|def, sets}` |

Все запросы — с таймаутом (5 с для API, без таймаута для потока) и типизированной ошибкой
`ApiError {kind: network|timeout|http|parse}`. Поддержка Basic-auth (логин/пароль сервера, если включены).

## Экраны

1. **Подключение** — список сохранённых серверов (имя, адрес, статус/версия), добавление вручную,
   автопоиск: перебор `/24`-подсети ТВ на портах 8090 и 5665 запросами `/echo` с ограничением параллельности.
   Последний сервер открывается автоматически при запуске.
2. **Библиотека** — сетка постеров; вкладки: Все / Фильмы / Сериалы / Музыка / Прочее (по `category`);
   ряд «Продолжить просмотр» (из `/viewed` с timecode). Автообновление списка каждые 10 с,
   пока экран активен — торренты, добавленные с телефона через веб-интерфейс TorrServer, появляются сами.
3. **Торрент** — заголовок, постер, размер, пиры; файлы сгруппированы по сезонам (парсинг `SxxEyy`,
   `1x02`, папок `Season N`), видео отдельно от прочих файлов; отметки просмотренного, прогресс-полоски.
   Действия: Воспроизвести / Продолжить, Плейлист, Удалить, Снять отметки.
4. **Плеер** — см. ниже.
5. **Добавить** — поле magnet/хеш/URL .torrent + поиск (rutor и torznab, переключатель источника);
   результат → `add` с title/poster/category.
6. **Плейлист** — открыть M3U/M3U8 по URL или плейлист торрента; парсинг `#EXTM3U`, `#EXTINF`
   (длительность, название, `tvg-logo`, `group-title`); воспроизведение подряд. HLS (`.m3u8` медиаплейлисты)
   отдаются в `<video>` напрямую — webOS играет HLS нативно.
7. **Настройки**
   - Приложение: язык аудио и субтитров по умолчанию, шаг перемотки (10 с, ускорение при удержании),
     автопереход к следующей серии (вкл/выкл, таймер 10 с), стиль субтитров (размер, цвет, фон),
     показывать оверлей статистики.
   - Сервер: основные `BTSets` (размер кэша, предзагрузка %, лимиты соединений, скорость),
     кнопка «по умолчанию».

## Плеер

- `<video>` с URL `/stream?...&play`; аппаратное декодирование ТВ (MKV/MP4/TS/AVI/WebM, H.264/HEVC/VP9/AV1,
  HDR10/HLG/Dolby Vision, AAC/AC3/EAC3/DTS — в пределах возможностей модели).
- Дорожки: имена и языки из `/ffp`; переключение через `video.audioTracks`/`video.textTracks`,
  на старых webOS — fallback через Luna (`webosMedia.ts`). При старте выбираются дорожки по языкам из настроек.
- Внешние субтитры (текстовые файлы SRT/VTT/ASS в том же торренте) — загружаются через `/stream`,
  парсятся `lib/subtitles.ts`, рисуются своим оверлеем со стилем из настроек.
- Прогресс: каждые 15 с и при выходе → `/viewed set {timecode}`; при ≥ 90 % файл считается просмотренным.
  При открытии — предложение «Продолжить с 23:14 / Сначала».
- Следующая серия: на последних 30 с (или по `ended`) — плашка с таймером.
- Оверлей статистики (кнопка Info / зелёная): скорость загрузки, пиры, заполнение кэша, битрейт/кодеки из ffprobe.
- Ошибка декодирования → экран с информацией ffprobe (кодек, профиль) и подсказкой, что формат не поддерживается ТВ.

## Управление

- Пульт: стрелки — навигация; OK — выбор/пауза; Back — назад по стеку экранов (на корне — выход с подтверждением);
  ←/→ в плеере — перемотка с ускорением; ↑ — меню дорожек; ↓ — панель управления;
  Play/Pause/Stop/FF/RW/Channel± — медиа-клавиши; цветные кнопки — быстрые действия
  (красная — удалить, зелёная — статистика, жёлтая — дорожки, синяя — настройки).
- Magic Remote и тачпад LG ThinQ: все интерактивные элементы кликабельны мышью, hover переводит фокус;
  при появлении указателя (`cursorStateChange`) навигация переключается в режим мыши.
- Ввод текста: обычные `<input>` — работают экранная клавиатура webOS и клавиатура телефона в LG ThinQ.

## Хранение

- localStorage: список серверов, активный сервер, настройки приложения, кэш последнего списка торрентов
  (для мгновенного старта).
- Сервер (`/viewed`): прогресс и отметки просмотренного — общие для всех ТВ.

## Обработка ошибок

- Сервер недоступен при старте → экран подключения с ошибкой и кнопкой «Повторить».
- Сетевые ошибки в экранах → тост + сохранение последнего успешного состояния.
- Плеер: `stalled/waiting` → индикатор буфера с процентом из `/cache`; ошибка `<video>` → экран ошибки,
  не падение приложения.
- Нет `/ffp` (сервер без ffprobe) → дорожки берутся только из `<video>`.

## Тестирование

- Vitest: API-клиент (моки fetch), discovery (моки), парсеры M3U/субтитров/серий, хранилище, форматирование,
  выбор дорожек по языку.
- Ручная проверка: `npm run dev` в браузере против реального TorrServer `192.168.1.191:5665`
  (TorrServer отдаёт CORS-заголовки; если нет — dev-прокси Vite).
- На ТВ: `npm run package` → `.ipk`, `ares-install`, `ares-launch` (режим разработчика ТВ).
