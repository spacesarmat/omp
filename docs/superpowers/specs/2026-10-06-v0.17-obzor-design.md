# OMP 0.16 — «Обзор» в «Каталоге» (design)

Date: 2026-10-05. Mockups (approved): https://claude.ai/artifact/VatvCxrBZ77EVjsfJyA8EX
Delivered first as the beta 0.17.0-beta.1 (beta channel since 0.15.5), then as 0.17.0.

## Goal

A Seerr-like way to discover films and series inside OMP: browse the newest titles from TMDB, open a card with the
description, rating, cast and seasons, then either find torrents for it with the existing search or subscribe to it
(«Хочу посмотреть»). Phone only in 0.16; the TV gets «Обзор» later (separate spec).

## Scope

In:
- «Каталог» tab on the phone gets a segmented switch «Мои / Обзор». «Мои» is today's library, unchanged (its chips
  «История / Все / Фильмы / Сериалы» stay). «Обзор» is new. The switch position is remembered (per device).
- «Обзор» home: one feed «Новинки» with chips «Все / Фильмы / Сериалы». Films: recent digital releases; series:
  series with new episodes/seasons now. Two-column poster grid, rating badge, «В медиатеке» badge when the title is
  already in the library. Infinite scroll by pages (TMDB page = 20).
- Search in «Обзор»: the header search icon opens a field; results are TMDB films and series (multi search, Russian),
  plus a link «Искать «<запрос>» на трекерах» that opens «Добавить» with the query.
- Film card: backdrop, poster, title, year, genres, runtime, TMDB rating, overview (collapsed to 4 lines, «Ещё»),
  cast (first 8 with photos), buttons «Найти раздачи» (primary) and «Хочу посмотреть».
- Series card: the same plus the seasons list (number, episode count, year; state «выходит: N из M» while airing,
  «В медиатеке» when matched). «Найти раздачи» on the card searches the series; on a season row, that season.
- «Найти раздачи»: opens «Добавить» with a ready query and runs the search. Film: «<русское название> <год>»;
  series: «<русское название>»; season: «<русское название> <N> сезон». Everything after is the existing flow.
- «Хочу посмотреть»: a sheet with the query (same rule as above) and quality chips «Любое / 1080p / 4K», button
  «Подписаться» → `addSubscription` in the monitoring («Новое»), notifications on. When a subscription with the same
  query exists, the card shows «Слежу за фильмом / за серией» instead and opens that subscription.
- Torrent filters (the results of «Найти раздачи» AND the ordinary search in «Добавить»): a «Фильтры · N» chip opens
  a sheet; active filters show as chips under the field; «Сбросить», «Показать N раздач». Groups, all parsed from the
  torrent title (plus size/seeds fields), OR within a group, AND between groups:
  - Качество: 720p / 1080p / 4K (today's «1080p / 4K» chips move here), HDR / Dolby Vision.
  - Источник: WEB-DL / BDRip / Remux; «Скрыть экранки» (CAMRip, TS, TC, TeleSync).
  - Размер, ГБ: от / до.
  - Сиды, не меньше: любые / 1 / 5 / 20.
  - Озвучка: Дубляж / Многоголосый / Оригинал; «Рус. субтитры».
  - Сериалы (only when the query is a series or a title has season marks): season N (from the card's season, else
    the seasons found in titles); «Только полный сезон» (no «Серии: 1-6 из 10» style partial releases).
  Titles that say nothing about a group pass that group's filter except «Скрыть экранки» and «Только полный сезон»,
  which only drop titles that match their marks. Filters are remembered per device (`tsp.searchFilters`) and apply
  to subscriptions created from the search (their `quality` takes the quality group).
  Mockup: artboard 8 «Фильтры раздач».
- «Каталог недоступен» state when TMDB does not answer (network, no key, blocked): text with the hint about the TMDB
  mirror in TorrServer settings, «Повторить»; «Мои» stays usable.
- TV fix shipped in the same beta: pointer/wheel scrolling inside an open dialog never scrolls the screen behind it
  (`src/ui/wheel.ts`): when the pointer is over a dialog (or any dialog is open), the scroll target is searched only
  inside that dialog; at its edge nothing scrolls and the event is consumed.

- Delete from the phone «Каталог» («Мои»): long press on a torrent opens a menu (Открыть / Смотреть на ТВ / Переименовать / Выбрать / Удалить); «Выбрать» starts a selection mode to delete several torrents at once with one confirmation; system «Назад» leaves the mode.

Out (later): TV «Обзор»; genres, «Похожее», trending; trailers; person pages; user ratings; Seerr/Radarr/Sonarr.

## TMDB access

- Config: the active TorrServer's `/tmdb/settings` (`TmdbConfig`: `APIKey`, `APIURL`, `ImageURL`, `ImageURLRu`), as the
  poster search already does (`src/lib/posterSearch.ts`). Its API mirror and the Russian image mirror
  (`imagetmdb.com` by default) are used as is.
- Fallback: when the server has no key, OMP's own TMDB v3 key built into the app (`TMDB_FALLBACK_KEY`, from a TMDB
  account the owner registers; until it is set the constant is empty and «Обзор» shows «Каталог недоступен» with the
  hint to add a key in TorrServer). The key is not a secret in the TMDB sense (app keys ship in clients), but it is
  never logged.
- Requests go through the native http on Android (no CORS), `language=ru-RU` (or `en-US` when the app is in English), `region=RU`, `include_image_language=
  ru,null,en`. Endpoints: `discover/movie` (release type digital 4, `release_date.lte` today, `sort_by=
  primary_release_date.desc`, `vote_count.gte=20`), `tv/on_the_air`, `search/multi`, `movie/{id}` and `tv/{id}` with
  `append_to_response=credits`.
- Cache: in memory per session plus `tsp.tmdbCache` in storage for lists (15 min) and cards (24 h), capped at 200
  entries; no personal data.
- Attribution: «Данные: TMDB» line at the bottom of «Обзор» and in «О приложении» (TMDB terms).

## Architecture

- `src/catalog/tmdb.ts` — pure: URL builders, response sanitizers (`sanitizeTitle`, `sanitizeCard`, `sanitizeSeasons`),
  query rules (`torrentQuery(title, season?)`), image URLs. Chromium 53 rules (shared code). Unit-tested with fixtures.
- `src/catalog/client.ts` — `createTmdbClient(cfg, http)` → `novelties(kind, page)`, `search(q, page)`, `card(kind, id)`;
  cache; errors mapped to `CatalogError` codes `offline | nokey | blocked | bad`.
- `src/sources/filters.ts` — pure: `parseRelease(title)` → `{res, hdr, source, cam, dub, mvo, original, rusSubs,
  seasons, episodes:{from,to,of}}` (Russian and English tracker conventions), `applyFilters(list, f)`,
  `sanitizeFilters`. Replaces `filterQuality` in `src/sources/view.ts`. Shared with the TV search later.
- `src/catalog/library.ts` — matches TMDB titles to library torrents (normalized title + year from `titleCore`, and
  the TMDB id when a torrent's poster came from TMDB) for the «В медиатеке» badges.
- Phone UI under `mobile/src/screens/catalog/`: `Discover.tsx` (feed + chips + grid), `CatalogSearch.tsx`,
  `TitleCard.tsx` (film and series), `WantSheet.tsx`; the segmented switch in `Library.tsx`. Routes: `{name:'title',
  kind, id}` for the card (Back returns to «Обзор» at its scroll position); «Найти раздачи» navigates to
  `{name:'add', query, run:true}` (new optional fields on the existing route).
- Monitoring reuse: `addSubscription({query, quality, sources:null, notify:true})`; `sameQuery` decides «Слежу».

## Errors and edge cases

- No active server: «Обзор» still works with the fallback key; «В медиатеке» badges are skipped.
- TMDB slow: skeleton posters; 15 s timeout per request; one retry on the next scroll.
- Title without a Russian name: the original title; query uses the Russian title when TMDB gives one, else original.
- Series card while a subscription exists: «Слежу за серией» opens it in «Новое».
- Offline mid-scroll: the loaded grid stays, a «Повторить» row at its end.

## Testing

- Vitest: `parseRelease` against a table of real-style tracker titles (rutracker, rutor, Kinozal, nnmclub; fictional
  names), each filter group alone and combined, the sheet and its chips, persistence.
- Vitest: sanitizers and URL builders against recorded TMDB fixtures (no network), query rules, cache expiry, library
  matching, the «Мои / Обзор» switch, card buttons (search route and subscription created), error states, the wheel
  fix (dialog edge does not scroll the screen).
- Device: phone (emulator + real), with the user's TorrServer key and with the fallback; beta 0.17.0-beta.1 installed
  via the beta channel (checks the channel end to end), then 0.16.0 replaces it.
