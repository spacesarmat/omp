# v0.10 «OMP для Android TV» — дизайн

Дата: 2026-10-02 · Основа: v0.9.1 (`main`) · Ветка `feat/v0.10-android-tv`
Макеты одобрены: https://claude.ai/artifact/KqoKfboi7hZFAz8aUksQKh

## Решения пользователя

- v0.10 — только Android TV; Samsung Tizen — v0.11.
- Видео на Android TV — собственный нативный плеер на Media3 (ExoPlayer).
- Телефон управляет Android TV через сам OMP на телевизоре (код сопряжения), без протокола пульта Google TV.

## Что видит пользователь

**Телевизор Android TV**
1. OMP в списке приложений с баннером (логотип + «OMP», «Open Movie Player»). Тот же APK, что на телефоне: на ТВ-устройстве открывается ТВ-интерфейс OMP (как на LG), на телефоне — телефонный.
2. Интерфейс ТВ — тот же, что на LG: подключение к серверу, каталог, история, раздача, настройки, «Подключить телефон», обновления. Навигация пультом Android TV: стрелки, OK, «Назад», медиакнопки.
3. Плеер — нативный (Media3), оформлен как плеер OMP на LG: внизу на затемнении название «Раздача · SxxEyy · Название», полоса перемотки, время «23:14 / 48:32», кнопки «Пауза», «Аудио: …», «Субтитры: …», «Следующая серия», строка подсказок «◀ ▶ перемотка · OK пауза · ▲ дорожки · Назад выход»; пометка «Управление с телефона» после первой команды с телефона. Перемотка стрелками с шагом из настроек, двойное нажатие — как на LG. Выбор дорожек и субтитров (встроенных и внешних файлов раздачи) — список поверх. Прогресс сохраняется локально и на TorrServer, как на LG; «Продолжить просмотр?» — в ТВ-интерфейсе до запуска плеера.
4. «Подключить телефон»: QR с сервером (как на LG) и блок «Код для пульта на телефоне» — 4 цифры, «На телефоне: OMP → Телевизор → «<имя ТВ>» → введите код», «Код действует 5 минут», кнопки «Готово» и «Новый код».
5. Обновление OMP на ТВ — из ленты `update-android.json` (тот же APK), установка через системный установщик (как на телефоне).

**Телефон**
6. Экран «Телевизор»: в одном списке LG (метка «LG webOS») и Android TV с OMP (метка «Android TV», строка «<IP> · OMP <версия>»). Android TV находится через NSD (`_omp._tcp`).
7. Нажатие на новый Android TV — нижняя панель «<имя> · Android TV», «На телевизоре откройте OMP → Настройки → «Подключить телефон» и введите код с экрана.», 4 поля, «Подключить», «Отмена». Неверный код — «Неверный код», истёкший — «Код устарел — нажмите «Новый код» на телевизоре».
8. «Смотреть на ТВ», «Продолжить / Сначала», «Сейчас играет», мини-плеер, «Звук и субтитры» — работают с Android TV так же, как с LG.
9. Пульт для Android TV: имя ТВ и «Android TV · подключён», пояснение «Пульт управляет OMP на телевизоре. Включение ТВ и другие приложения — пультом от телевизора.», крестовина и OK, «Назад», «Каталог», «Сейчас играет», «Клавиатура», громкость. Без кнопки питания, тачпада и кнопок каналов.

## Как это устроено

### Один APK, два интерфейса
- Сборка ТВ-интерфейса (`src/`, тот же код, что для LG) кладётся в `dist-mobile/tv/` (отдельный конфиг Vite, `base: './'`, современная цель — WebView Android TV не ниже Chrome 90; без legacy-плагина). `npm run build:mobile` собирает оба.
- `MainActivity`: если устройство — ТВ (`UiModeManager.currentModeType == UI_MODE_TYPE_TELEVISION` или `FEATURE_LEANBACK`), после старта моста загружает `<localUrl>/tv/index.html`.
- Манифест: `LEANBACK_LAUNCHER` в фильтре запуска, `android:banner` (320×180, рисуется скриптом иконок из логотипа), `uses-feature android.software.leanback` и `android.hardware.touchscreen` с `required="false"`.
- В ТВ-коде признак платформы `platform.kind`: `'webos'` или `'androidtv'` (есть `window.Capacitor` и плагин `OmpNative`). Всё webOS-специфичное (luna, Homebrew, PalmSystem, ipk-обновления) отключается на Android TV; обновление — APK.

### Клавиши
- Android TV «Назад» не доходит до WebView: `MainActivity` в ТВ-режиме перехватывает `KEYCODE_BACK` и отдаёт в страницу `keydown` с `keyCode: 461`. Медиакнопки (`PLAY`, `PAUSE`, `PLAY_PAUSE`, `FAST_FORWARD`, `REWIND`, `NEXT`, `PREVIOUS`, `STOP`) — в коды webOS (415, 19, 179, 417, 412, 33, 34, 413). Выход из приложения — «Назад» на корневом экране (каталог/подключение) закрывает Activity.

### Нативный плеер
- `PlayerActivity` (Media3 ExoPlayer + свой оверлей на View/Compose-free XML), запускается методом плагина `playNative({ queue, index, startAt, auth, seekStep })`; `queue[i] = { url, title, subtitle, hash, fileIndex, poster?, subtitles: [{ url, label }] }`. Basic-авторизация TorrServer — заголовком.
- События в страницу: `nativePlayerState` (раз в 1 с и при изменениях: `{ index, time, duration, paused, buffering, audio, subs }`), `nativePlayerClosed { index, time, duration }`.
- ТВ-код на Android TV: маршрут `player` вызывает `playNative` и показывает экран-заглушку; по событиям сохраняет прогресс (как `useProgressSync`) и отдаёт снимок в связь с телефоном (`setPlayerBridge`); команды телефона → метод `nativePlayerCommand(cmd)`. По `nativePlayerClosed` — назад на экран, откуда открыли.

### Управление с телефона
- На ТВ OMP запускает (только в ТВ-режиме) HTTP-сервер на порту 8095 и регистрирует NSD-службу `_omp._tcp` с именем устройства (`Settings.Global.DEVICE_NAME`) и TXT `v=<версия>`.
- Сопряжение: экран «Подключить телефон» запрашивает у плагина код (`pairingCode()` → 4 цифры, 5 минут). `POST /omp/pair {code, phone}` → `{ token }` (32 hex, хранится на ТВ; список телефонов — в SharedPreferences). Все остальные запросы — с `Authorization: Bearer <token>`; без него — 401.
- `GET /omp/info` (без токена) → `{ name, version, paired: false|true для этого токена }`.
- `POST /omp/launch { params }` → ТВ-код получает событие `remoteLaunch` и выполняет `runLaunchParams(params)` (те же параметры, что у LG: `server`, `torrent`, `file`, `t`, `report`, `magnet`, `play`). Приложение выводится на передний план.
- `POST /omp/attach { report }` — только подключить связь «Сейчас играет», без навигации.
- `POST /omp/key { name }` — `UP/DOWN/LEFT/RIGHT/ENTER/BACK` + `CATALOG`, `NOWPLAYING`: в WebView (или в плеер, если он открыт) как клавиши; `CATALOG` → маршрут каталога; `NOWPLAYING` → плеер, если есть текущая очередь.
- `POST /omp/text { text }` / `POST /omp/text { delete: n }` / `POST /omp/text { enter: true }` — ввод в сфокусированное поле.
- `POST /omp/volume { dir: 'up'|'down' }` — `AudioManager.adjustStreamVolume(STREAM_MUSIC, …, FLAG_SHOW_UI)`.
- Состояние плеера на телефон идёт прежним каналом `report` (ТВ шлёт POST на телефон раз в 500 мс).

### Телефон
- `SavedTv` получает `kind: 'lg' | 'atv'` (по умолчанию `'lg'`), для `atv` — `token` и `port`. `tvClient` выбирает транспорт по `kind`: для `atv` — HTTP к `/omp/*`; `launchOnTv`, кнопки пульта, текст, громкость — через него; `foregroundAppId`/`ompVersionOnTv` для `atv` — через `GET /omp/info`.
- Поиск: SSDP (LG) + NSD `_omp._tcp` (плагин `discoverOmpTvs`).
- Экран «Пульт» для `atv` — вариант из макета.

## Ограничения

- ТВ-код по-прежнему должен собираться и для webOS (Chromium 53): новые ветки для Android TV не используют несовместимый синтаксис в общих модулях.
- Телефон управляет только OMP на Android TV.
- Встроенный TorrServer на Android TV — вне рамок v0.10 (экран подключения ТВ без карточки «Запустить на этом ТВ»).
- Без строк соавторства; тексты только на русском.
