## LG (webOS) и общий ТВ-интерфейс

1. **Панель плеера скрывается всегда:** таймер скрытия (4 с) перезапускается при каждом переходе в воспроизведение (`playing`, конец буферизации, команды с телефона, перемотка); если таймер сработал на паузе — панель остаётся до следующего воспроизведения, затем прячется через 4 с.
2. **Прокрутка экранов курсором:** на ТВ любой прокручиваемый экран (настройки, раздача, списки) прокручивается колесом/жестом прокрутки пульта Magic Remote и командой прокрутки с телефона; наведение курсора на элемент даёт ему фокус (как сейчас), без принудительной прокрутки.
3. **Строки настроек:** значение («‹ Русский ›») всегда в своей строке, справа, по центру по вертикали (ошибка вёрстки на webOS).
4. **«История» с источником** (ТВ LG и Android TV): над карточками фильтр «Все / С телевизора / С телефона»; на карточке строка источника: «Телевизор · <когда>» или «Телефон «<имя>» · <когда>» (имя ТВ на ТВ не пишем — «Телевизор»); когда — «сегодня 21:40», «вчера 22:15», «30 сентября».

## Журнал просмотров на TorrServer

- Хранится в поле `data` раздачи (TorrServer: `action: "set"` с `hash`, `title`, `poster`, `category`, `data`). В `data` — JSON; OMP пишет только ключ `omp` и сохраняет все остальные ключи (их используют другие клиенты, например Lampa). Если `data` не JSON — OMP её не трогает и журнал для этой раздачи не ведёт.
- Формат: `"omp": { "v": 1, "h": [ { "f": <fileIndex>, "t": <секунды>, "d": <длительность>, "at": <unix ms>, "src": "tv"|"phone", "name": "<имя устройства>" } ] }` — не больше 20 записей на раздачу, новые в начале; одна запись на файл и источник (обновляется).
- Пишут: ТВ (LG и Android TV) при старте файла и при выходе из плеера (раз в сеанс, не каждые 15 с); телефон — при запуске на ТВ («Смотреть на ТВ»: источник «phone», имя телефона) и при просмотре во внешнем плеере (старт).
- «История» строится из журнала (последняя запись по каждой раздаче/файлу); раздачи без журнала — как раньше (из TorrServer `viewed` и локального прогресса) с источником «Телевизор».

## Телефон (Android)

5. **Мини-плеер «Сейчас играет»** — только на вкладках «Каталог» и «Пульт».
6. **«Дальше: …»** на «Сейчас играет»: «чистое» название (без расширения и точек), перенос, до 2 строк, не выходит за рамку.
7. **Категория при добавлении:** на «Добавить» под ссылкой ряд «Без категории / Фильмы / Сериалы / Музыка / Прочее» (значения TorrServer: `""`, `movie`, `tv`, `music`, `other`); у результатов поиска — кнопка «<категория> ▾» с тем же выбором. Категория угадывается по названию (сезон/серии/SxxEyy → «Сериалы», FLAC/MP3/дискография → «Музыка», иначе «Фильмы»), пользователь может поменять.
8. **Обновление каталога жестом:** потянуть список вниз от верха → индикатор «Обновляю…» → перезагрузка списка.
9. **Пульт без прокрутки:** вся раскладка помещается по высоте экрана (крестовина и кнопки ужимаются на низких экранах); кнопка «Настройки тачпада» в шапке.
10. **Настройки тачпада** (нижняя панель): «Скорость курсора» 1–5 (по умолчанию 3), «Ускорение» (вкл), «Касание = щелчок» (вкл); прокрутка двумя пальцами по тачпаду отправляет на LG прокрутку (кадр `type:scroll`). Хранится в `tsp.touchpad`.
11. **«Настройки сервера»** — кнопка прямо в блоке «TorrServer на телефоне».
12. **«Вопросы и ответы»** — пункт в «Настройках», экран со списком раскрывающихся вопросов: установка на LG (Homebrew Channel, вручную), на Android TV, на телефон; что такое TorrServer; TorrServer на телефоне; подключение телефона к ТВ (LG — разрешение, Android TV — код); сервер не находится (одна сеть, VPN, изоляция клиентов); нет звука AC3/DTS; управление плеером с телефона.
13. **«Назад» на главных вкладках** сворачивает приложение (не закрывает), чтобы встроенный сервер продолжал работать.
14. **Значок ТВ в шапке каталога** — только иконка; зелёная, когда ТВ подключён; `aria-label` с именем ТВ и состоянием.
