# Адаптер внутренних компонентов phone и TV

## Цель

Дать редактору доступ к реальным внутренним шаблонам phone/TV без ручной разметки сотен компонентов.

## Подход

Выбран общий DOM-адаптер вместо правки каждого экрана или хрупких `nth-child` селекторов. Он назначает стабильные типы по semantic HTML и существующим CSS-классам:

- `legacy-page`: корень preview.
- `button`: `button` или `.button`.
- `input`: `input` или `.text-input`.
- `card`: `.m-card`.
- `choice-row`: `.choice-row`.

Уже существующие `data-design-id` не перезаписываются. Адаптер ставит `data-design-id`, `data-design-component` и `data-design-overrides` через `activeOverrideIds`. `MutationObserver` обрабатывает динамические экраны, обновление темы проходит повторно по дереву.

## Изменения

- `DESIGN_ELEMENTS` пополняется четырьмя общими шаблонами с существующими цветами и размерами.
- `isDesignElementAvailable` разрешает все пять типов для phone/TV.
- `PhonePreview` и `TvPreview` подключают observer и CSS-потребители токенов для новых типов.
- Экспорт проверяет новые элементы на реальных маршрутах.
- Панель показывает пять шаблонов вместо одного.

## Ограничения

- Не добавляются типы без явного списка: неизвестные блоки не превращаются в карточки.
- Production DOM не изменяется, адаптер работает только в preview.
- Внутреннее состояние компонентов и бизнес-логика не меняются.

## Проверка

- Unit-тест назначения ID и overrides, сохранения существующих ID и dynamic child.
- Phone/TV тесты реальных компонентов и пяти слоёв.
- Проверка phone contrast в экспорте.
- Полный набор, TypeScript, сборка и browser edit/undo.
