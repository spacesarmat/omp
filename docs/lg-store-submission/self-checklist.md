# OMP - App Self Checklist (draft)

Черновик по https://webostv.developer.lge.com/distribute/app-self-checklist (страница от 18 ноября 2026; полный xlsx LG на странице скачивается отдельно, ниже - пункты, которые страница публикует). Ответы сняты с кода store-сборки. Где без телевизора ответ не закрыть, стоит «проверить на ТВ».

Поддержка: ompplayerandroid@gmail.com. Политика: https://omp-player.online/privacy.

Сборка: `npm run package:store`, id `com.spacesarmat.torrplayer`. Публичного поиска раздач нет. Контент приходит только с TorrServer, который поднимает пользователь.

## UX - обязательное

| Пункт LG | Ответ | Откуда |
| --- | --- | --- |
| Все выбираемые элементы работают со стрелками, OK и Back | Pass в коде. проверить на ТВ | Фокус: `@noriginmedia/norigin-spatial-navigation`, `src/ui/keys.ts`, `src/platform/keys.ts`. Цветные кнопки OSD не обязаны дублироваться стрелками. |
| Те же элементы работают курсором Magic Remote и OK | проверить на ТВ | Клик и движение мыши есть у плеера (`src/screens/Player.tsx`). Подсветка фокуса завязана на 5-позиционный фокус. Нужно пройти курсором каталог, подключение, настройки и плеер. |
| Back на входном экране показывает Home (webOS 23-25) | проверить на ТВ | С каталога без открытого поиска Back не листает историю. `unhandledBack` в `src/app.tsx` спрашивает «Выйти из приложения?» и после подтверждения вызывает `window.close()`. Подсказка в каталоге: «Назад - выход». Нужно убедиться, что QA принимает шаг с подтверждением и что Home открывается. |
| У каждого объекта есть эффект выбора | Pass в коде. проверить на ТВ | `.focused`: жёлтый фон, у кнопок увеличение (`src/styles.css`). Исключений для обычных кнопок нет. |

## UX - рекомендации

| Пункт LG | Ответ | Откуда |
| --- | --- | --- |
| Разрешение 1920x1080 | Pass | `webos/appinfo.json`: `"resolution": "1920x1080"`. 4K масштабируется тем же корнем 1920 (`src/app.tsx`). проверить на ТВ картинку на 1080p и 4K. |
| Кнопки не меньше 75x75 на 1080p | Частично. проверить на ТВ | Текстовые кнопки выше за счёт padding 16px; на подключении `min-height: 64px`. Иконки шапки `.icon-button` - 60x60, это ниже рекомендации 75. |
| Текст не меньше 20px на 1080p | Pass для обычного UI | `body` - 28px (`src/styles.css`). Подписи режима тестирования могут быть меньше; переключатель есть только у версии `x.y.z-beta.N` (`isBetaBuild`). Стабильная версия его прячет. |
| Состояния элементов видны сразу | Pass в коде. проверить на ТВ | Обычное, `.focused`, `.active` у вкладок, disabled у поиска на вкладках, которых в store нет. |
| Пока данные грузятся, есть индикатор | Pass | `Spinner` в каталоге и «Подключение...» на экране сервера. |
| Колесо Magic Remote листает в ту же сторону | проверить на ТВ | `installWheelScroll` в `src/app.tsx`. |
| Виртуальная клавиатура LG | проверить на ТВ | Поля адреса, логина и поиска по медиатеке - обычные input. Клавиатура должна выезжать снизу. |
| Управление воспроизведением есть на экране, не только на пульте | Pass в коде. проверить на ТВ | Оверлеи плеера: пауза, перемотка, дорожки, главы. |
| Play ставит на паузу и снова запускает, и наоборот для Pause | проверить на ТВ | Медиаклавиша play/pause одна и та же в `src/screens/Player.tsx` (переключает). Отдельных двух кнопок с одной функцией нет. |

## Privacy and credentials

| Пункт LG | Ответ | Откуда |
| --- | --- | --- |
| В исходниках store-ipk нет паролей, ключей и токенов строками | Pass для подачи | Пароль TorrServer вводит пользователь, он не зашит. Ключ TMDB берётся из окружения сборки или с сервера пользователя, в репозиторий не кладётся. Токен устройства появляется после запроса, не как литерал в appinfo. |
| Имена файлов не содержат passwd, password, credential, token | Pass | В `dist-store` таких имён нет: `index.html`, `appinfo.json`, `icon.png`, `largeIcon.png`, скрипты сборки. |
| Диагностика и сбои | Pass в коде | В store-сборке переключатель выключен, пока его не включат (`src/store/settings.ts`). Выключенный не шлёт события и отчёты (`src/report/crash.ts`, `src/report/presence.ts`). Политика это повторяет. |
| ACG | Pass в appinfo ipk. проверить на ТВ | `"requiredACG": ["network.query"]`. См. таблицу в `README.md` этой папки. На webOS TV 26 нужно убедиться, что `getStatus` не отвечает Denied и что запасной вызов `com.webos.media` не обязателен для базового воспроизведения. |

## Что нельзя подписать без телевизора

- Курсор Magic Remote по всем экранам.
- Back с каталога и диалог выхода открывают Home на webOS 23-25.
- Колесо, виртуальная клавиатура, play/pause с пульта и с экрана.
- Поиск TorrServer в сети после включения ACG.
- Выбор дорожки, когда у ролика нет HTML-списка `audioTracks` / `textTracks`.
- Иконка в лаунчере без прозрачных углов и без белой подложки.
