# OMP - LG Content Store: QA / review instructions

Инструкция для тестировщика LG. Store-сборка OMP - плеер для СВОЕГО TorrServer; публичного поиска в приложении нет, весь контент приходит с сервера, который поднимает тестировщик. Ниже - как подготовить стенд и что проверить.

## 1. Поднять TorrServer в той же сети, что и ТВ
1. Скачайте TorrServer: https://github.com/YouROK/TorrServer/releases (сборка для вашей ОС).
2. Запустите. По умолчанию веб-интерфейс и API доступны на порту 8090. Запомните IP машины в локальной сети (например, 192.168.1.50).
3. ТВ и машина с TorrServer должны быть в одной сети.

## 2. Добавить тестовый контент (на выбор)
Вариант A - тестовая раздача:
- Добавьте в TorrServer любой тестовый торрент с легальным содержимым (например, публичный тестовый ролик / open-source фильм). Дождитесь, что раздача появилась в каталоге TorrServer.

Вариант B - HLS-поток без торрента (проще всего):
- OMP умеет открывать плейлисты M3U/HLS. Подготовьте тестовый HLS-поток и откройте его в OMP через «Плейлисты» (URL). Это проверяет плеер без контента в TorrServer.

## 3. Подключить OMP на ТВ к серверу
1. Установите и откройте store-сборку OMP на LG ТВ.
2. На экране подключения укажите адрес TorrServer (IP:8090) или выберите найденный сервер.
3. Откроется каталог вашего сервера.

## 4. Что проверить
- Каталог: категории, фильмы/сериалы, сезоны; постеры/описания (TMDB).
- Воспроизведение: запуск видео, аппаратное декодирование, пауза/перемотка.
- Плеер: выбор аудиодорожки, субтитры, главы, пропуск заставки/титров (если есть в контенте).
- История и продолжение с места остановки.
- Телефон как пульт (опционально): приложение OMP на телефоне в той же сети -> запуск на ТВ, пауза, перемотка, громкость.
- Плейлисты M3U/HLS (вариант B).

## 5. Особенности store-сборки (ожидаемое поведение)
- Нет поиска раздач в интернете и вкладок «Обзор»/«Новое» - контент только с вашего TorrServer / из плейлиста.
- Нет кнопки «Найти раздачу» / «В лучшем качестве».
- Обновление приложения - через LG Content Store (внутреннего обновления/ссылок на сторонние пакеты нет).
- Диагностика (отправлять шаги использования) и отчёты о сбоях выключены, пока их не включат в Настройках. Статистика для ранжирования раздач не отправляется.
- Лупа в каталоге ищет по названиям уже добавленной медиатеки. Кнопки поиска раздач в интернете нет.

## 6. Тестовые данные / аккаунт
- Аккаунт для воспроизведения не требуется.
- Тестовый контент готовит тестировщик (легальное содержимое); разработчик не предоставляет каталог контента.
- Поддержка: ompplayerandroid@gmail.com. Политика: https://omp-player.online/privacy.
