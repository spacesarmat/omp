# Ручные проверки перед выпуском

Автотесты не проверяют связку устройств, системные функции Android и webOS и работу с настоящим TorrServer. Перед большим выпуском пройдите этот список; отметьте, что проверено, и запишите, что не так.

## Телефон (Android)

**Сервер и каталог**
- [ ] Сервер находится сам в той же Wi-Fi-сети; ручное добавление с логином и паролем работает
- [ ] Каталог открывается; вид (плитки / список / строки) и сортировка переключаются
- [ ] Потянуть каталог вниз: шапка и вкладки стоят, тянется список, значок под вкладками; отпустить — каталог обновился
- [ ] «История»: фильтр «Все / С телевизора / С телефона», строка источника и время

**Добавление и обложки**
- [ ] Magnet-ссылка из браузера открывает OMP на «Добавить»; после «Добавить» сразу открывается карточка раздачи
- [ ] Категория угадывается по названию, её можно поменять
- [ ] Единый поиск: один запрос по «Всем источникам»; у результата «Добавить» и «На ТВ»; одинаковые раздачи склеены, «ещё в …» показывает остальные источники
- [ ] Поиск по каждому источнику отдельно (rutor, nnmclub, Anidub, BigFANGroup, torrent.by, Torznab, rutracker): результаты есть, «Добавить» кладёт раздачу в TorrServer (у Anidub — по .torrent-ссылке)
- [ ] «Настройки» → «Источники поиска»: переключатели сохраняются; закрытый источник не ломает остальные, строка показывает «не отвечает»
- [ ] rutracker: «Войти» с верным логином — статус «работает», поиск находит раздачи; с неверным — ошибка, пароль в поле не остаётся
- [ ] rutracker: в `adb logcat` во время входа и поиска нет логина и пароля
- [ ] Если rutracker закрыт Cloudflare: понятное сообщение и подсказка про Jackett / Prowlarr, остальные источники продолжают отвечать
- [ ] После обновления с 0.11 «Что нового» открывается один раз; повторно — только по строке с версией в «Настройках»
- [ ] «Настройки сервера» → «Ключ TMDB для обложек»: ввести ключ — у новой раздачи обложка появляется сама (до ~30 с)
- [ ] У старой раздачи без обложки — кнопка «Найти обложку» в карточке; «Найти обложки для раздач без обложек» в настройках сервера

**Новое и фоновый мониторинг**
- [ ] Пять вкладок внизу (Каталог, Новое, Добавить, Пульт, Настройки); переход между ними листанием вбок, вкладка «Новое» со значком о непросмотренном
- [ ] «Новое» → «Лента»: раздачи с rutor, nnmclub и torrent.by по «Фильмам», «Сериалам», «Аниме»; фильтр 1080p+; «Добавить» и «На ТВ» работают; выключенный источник не ломает остальные
- [ ] Новая подписка: правила (источники, качество, сиды) сохраняются; первая проверка идёт без уведомлений; позже появившаяся раздача даёт уведомление и значок «N новых»
- [ ] Фоновая проверка при закрытом OMP (смахнуть из недавних): через заданный интервал приходит уведомление о свежей раздаче; «Проверить сейчас» делает то же вручную
- [ ] Кнопки в уведомлении при убитом приложении: «Добавить» кладёт раздачу на сервер и показывает «Добавлено на сервер»; «Смотреть на ТВ» открывает OMP с готовым запуском и ничего не включает без нажатия
- [ ] «Добавить» из фонового уведомления доходит до встроенного TorrServer на этом же телефоне (сервер запущен); при выключенном сервере раздача не теряется и остаётся во вкладке «Новое»
- [ ] Уведомления не повторяются после убийства приложения и перезапуска телефона: об уже показанной раздаче второе уведомление не приходит
- [ ] «Заменить» на настоящем сериале: у новой раздачи название и обложка, история просмотра и места остановки и настройки «Пропуск» перенесены, старая раздача удалена только после успеха; при ошибке старая остаётся
- [ ] «Смотреть на ТВ» на карточке новых серий: сначала замена, потом запуск; «Не следить» убирает карточку и больше не напоминает об этом сериале
- [ ] «Настройки» → «Мониторинг»: «Только через Wi‑Fi» — на мобильной сети проверка пропускается, на Wi‑Fi идёт; смена интервала действует; выключение «Проверять в фоне» останавливает проверки
- [ ] Запрос разрешения на уведомления появляется один раз (не несколько подряд); после отказа в «Мониторинге» видна кнопка «Разрешить уведомления»

**Просмотр**
- [ ] «Смотреть на ТВ» — выбор «Продолжить с …» / «С начала», запуск выбранной серии
- [ ] Внешний плеер (VLC и т. п.) открывает поток
- [ ] «Сейчас играет»: пауза, перемотка, громкость, следующая серия, «Дальше: …»
- [ ] «Сейчас играет» с файлом с главами: список глав, текущая подсвечена, метки на полосе, кнопки соседних глав
- [ ] Карточка раздачи, блок «Пропуск»: переключатели «Пропускать заставку» и «Пропускать титры» сохраняются и видны на ТВ
- [ ] Файл без глав: ручные метки заставки (начало и конец) сохраняются для следующих серий

**Пульт**
- [ ] Пульт помещается на экран без прокрутки; кнопки, крестовина, громкость
- [ ] Тачпад: курсор, касание = щелчок, прокрутка двумя пальцами; «Настройки тачпада»
- [ ] Включение ТВ с телефона (Wake-on-LAN) и выключение

**TorrServer на телефоне**
- [ ] Запуск и остановка встроенного сервера; уведомление, пока он работает
- [ ] Другой телефон или ТВ видит этот сервер в сети
- [ ] «Назад» на главном экране сворачивает приложение, сервер продолжает работать
- [ ] Проверка новой версии TorrServer

**Прочее**
- [ ] «Вопросы и ответы» открываются, ссылки ведут куда надо
- [ ] «Проверить обновление» видит новую версию OMP

## Выпуск 0.14: журнал, копия, Android TV и помощник установки

Проверки идут по одной; CI Android проверен автоматически и сюда не входит.

**Журнал ошибок (телефон)**
- [ ] «Настройки» → «Журнал ошибок»: записи есть (запуск OMP с версией, Android и WebView); фильтры «Все / Ошибки / Мониторинг» работают
- [ ] Вызвать ошибку (выключить сервер и открыть каталог): появилась запись «сервер», в ней нет адреса сервера; «Очистить» стирает журнал
- [ ] «Сообщить об ошибке на GitHub»: открывается страница новой задачи с версией OMP, Android и моделью; журнал в буфере обмена, вставляется в задачу; в тексте нет паролей, адресов и названий раздач
- [ ] «Поделиться журналом»: системное «Поделиться» с файлом `omp-журнал-<дата>.txt`, файл открывается и читается
- [ ] Android TV: «Настройки» → «Журнал» показывает последние записи; «Очистить журнал» спрашивает подтверждение

**Источники и rutracker на Android TV**
- [ ] «Настройки» → «Источники поиска» на ТВ: список как на телефоне, переключатели работают пультом, состояние каждого источника видно
- [ ] rutracker на ТВ: «Войти», логин и пароль пультом и через «Клавиатуру» на телефоне; верный вход — «вход выполнен», поиск rutracker работает; неверный — понятная ошибка, пароль не остаётся
- [ ] Телефон → «Источники поиска» → «Передать на телевизор» (с отметкой rutracker): на телефоне «Передано», на ТВ время передачи и имя телефона, вход на rutracker работает без набора пароля
- [ ] Передача с неверным паролем rutracker: телефон показывает причину, прежний вход на ТВ остался рабочим
- [ ] Передача при выключенном OMP на ТВ и при выключенном ТВ: понятное сообщение, повтор после запуска проходит

**Ручные отметки заставки и титров на ТВ**
- [ ] Android TV: карточка раздачи → «Заставка и титры» → окно с «Заставка с / до» и «Титры: последние»; стрелки ◀ ▶ двигают на 5 с, удержание — на 30 с; «Сбросить», «Сохранить», «Назад» (без сохранения)
- [ ] LG: то же окно; удержание стрелки на пульте Magic Remote и на обычном пульте даёт шаг 30 с (если нет — шаг 5 с, записать)
- [ ] Сохранённые отметки видны на телефоне в «Пропуске» и срабатывают при просмотре серии

**Резервная копия**
- [ ] «Настройки» → «Резервная копия» → «Сохранить копию…»: файл `omp-копия-<дата>.json` уходит через «Поделиться»; в файле нет паролей трекеров
- [ ] «Восстановить из файла…» на чистой установке (или после очистки данных приложения): выбор файла работает, показано содержимое, после подтверждения серверы, телевизоры, подписки и источники вернулись; rutracker просит вход заново
- [ ] Повреждённый или чужой файл отклоняется понятным сообщением, данные не меняются

**Помощник установки: поиск**
- [ ] «Установить OMP на телевизор»: LG находится, показаны модель, webOS и состояние OMP / Homebrew Channel (при запросе на ТВ нажать «Разрешить»)
- [ ] Android TV находится в списке (модель, Android); при отказе поиска работает «Ввести IP вручную» для LG и Android TV
- [ ] Телевизор, уже подключённый к телефону, после проверки остаётся активным (или помощник спрашивает перед переключением)

**Установка на LG через режим разработчика**
- [ ] Пошаговая проверка: аккаунт, приложение Developer Mode, Dev Mode Status, Key Server; неверный код Passphrase сразу даёт понятную ошибку
- [ ] Установка с телефона: прогресс, итог «OMP установлен», OMP появился в списке приложений ТВ и запускается; временные файлы на ТВ удалены
- [ ] Вариант с Homebrew Channel: ставится и открывается; если не поставился — OMP всё равно установлен, причина показана
- [ ] Обновление OMP на ТВ, где он уже стоит
- [ ] Напоминание: после установки отметка «Напомнить продлить режим разработчика» запрашивает разрешение на уведомления; уведомление приходит (проверить подменой срока или вручную); снятие отметки отменяет напоминание

**Установка на Android TV по adb**
- [ ] На приставке включена «Отладка по сети»: помощник подключается, на ТВ запрос «Разрешить отладку?», после подтверждения OMP устанавливается; повторная установка поверх (обновление) проходит
- [ ] Отладка выключена или запрос отклонён: понятная ошибка с подсказкой следующего шага
- [ ] Приставка Android 11+ только с «Беспроводной отладкой»: помощник предлагает «Скачать APK» и ссылку на вопрос; APK скачивается со страницы релиза и ставится вручную
- [ ] После установки Key Server и отладку по сети выключены, OMP на ТВ работает
